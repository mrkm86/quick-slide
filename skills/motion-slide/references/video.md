# 動画にする（`scripts/record.py`）

> 経緯: 2026-10-06 の試し。判断は [ADR 0002](../docs/adr/0002-video-by-virtual-clock.md)。

同じ `index.html` から、自動再生をそのまま mp4 にする。台本は変えない。

```bash
python3 -I <このスキルのフォルダ>/scripts/record.py <出力先>/index.html            # → <出力先>/video.mp4
python3 -I …/record.py <index.html> --start 3.1 --seconds 45 --out s3.mp4             # 一部だけ（場面.拍 は 1 始まり）
```

| | |
|---|---|
| 画 | 1920×1080・30fps（`--fps`）・H.264（`--crf` 既定 18）。操作ボタンとマウスの矢印は隠す（`--keep-ctrl` で残す） |
| 長さ | 既定は `--start` の拍から終わりまで（自動再生の時刻表）＋1.5 秒。拍の長さは台本の `data-dur` |
| 効果音 | ページが鳴らした音の記録を、ページと同じ音で時刻どおりに重ねる（`--no-sfx` で無し） |
| BGM | HTML に `<audio id="bgm">` があれば、時刻表の位置から重ねる。音量は `ms-config` の `bgmVolume`（`--no-bgm` で無し） |
| かかる時間 | 動画の長さの約 3.5 倍（3分22秒で約12分・実測）。長いものは裏で回す |

## 仕組み

`scripts/vclock.js` をページより先に差し込み、ページの時計を止める。

- `setTimeout` / `setInterval` / `requestAnimationFrame` / `performance.now` / `Date.now` を差し替える
- CSS のトランジションとアニメーションは `document.getAnimations()` で捕まえて止め、`currentTime` を時計に合わせる
- 1コマごとに時計を 1/30 秒進め、タイマーと rAF を順に起こしてから撮る

そのため、コマ落ちが無く、何度撮っても同じ絵になる。

## 撮れないもの・気をつけること

- **LIVE の部品は触られない。** 動画には既定の値の見た目が映る（入力欄・チェックリストは最初の状態のまま）
- **乱数で見た目が変わる仕掛けは、撮るたびに変わる。** 見た目に乱数を使わない（使うなら種を固定する）
- **`<video>` やキャンバスに時刻で描くもの**（`Date` を直接持つライブラリなど）は時計に従わないことがある。足すときは短く撮って確かめる
- **声は入らない。** 話す台本を声にして重ねるのは未対応（tts で拍ごとに読み、`data-dur` を声の長さに合わせる形が候補）

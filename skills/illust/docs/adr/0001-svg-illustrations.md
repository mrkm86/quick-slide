# 0001 挿絵は SVG で描き、確かめて絞ってから PNG にする（独立したスキル）

- 日付: 2026-10-13
- 状態: 採用

## 決めたこと

- 挿絵（中身を表す動かない絵）は、書く側（台本係の LLM・人）が **SVG を 1 枚**書く。画像生成（Codex）は使わない
- 描き方は 2 つ: **A アイコンを組み合わせる**・**B 丸・角丸・太い線だけで人や物や場面を描く**。場面に合わせて書く側が選ぶ
  （試作で両方とも資料に使える出来だった。2026-10-13）
- アイコンは `<icon name x y size fill/>` と名前で書き、`illust.py` が共有の置き場（`skills/dads/icons`。Material Symbols の
  部分集合・html-slide の型のアイコンと同じもの）の形に展開する。長い形のデータを書かせない（書く量と書き損じを減らす）
- **描いてよい形だけに絞る**（`svgclean.py`）: 形と文字の要素・許した属性だけを残す。スクリプト・`<foreignObject>`・
  `<image>`・`<use>`・`<style>`・アニメーション・`on…` の属性・`#id` 以外を指す `url()` は落とす。DOCTYPE・ENTITY は受けない。
  書いた側に直させるもの（読めない・viewBox が無い・知らないアイコン・大きすぎる）は `NG:` の行（rc=2）
- PNG は Chrome で撮る（地は透明・長い辺 1920 が既定）。Chrome は `--chrome`・`ILLUST_CHROME`・PATH・よくある置き場の順に探す
- 配色はブランドの主役の色から作る（淡い段・濃い段・灰色・人の肌と髪）。挿絵がページの色にそろう
- **独立したスキル**にする。html-slide（画像の枠）と motion-slide（場面の HTML）の両方で使うため。エンジンからは呼ばない
  （エンジンはほかのスキルを呼ばない・素材はファイルで受ける）。Quick Slide のサーバが呼び、html-slide には PNG のファイルを渡す

## 却下した案

| 案 | 却下の理由 |
|---|---|
| html-slide の中に挿絵の仕組みを持つ | motion-slide でも使う。エンジンの外の素材づくりで、エンジンの機能ではない |
| SVG をそのまま PPTX に入れる | python-pptx は SVG を絵として置けない。図形に写す道（PowerPoint で直せる）は、使える形を絞ってから別に試す |
| Chrome の `scriptEnabled=false` でスクリプトを止める | 指定すると撮影そのものが動かない（2026-10-13 に確かめた）。スクリプトは絞る段で落とす |
| アイコンの形のデータを書く側に書かせる | 1 つで数百字あり、書く量と書き損じが増える |

## 残したこと

- 図形のまま PPTX に入れる（PowerPoint で色や形を直せる）道
- 描いたあとに撮って書いた側に見せ、直させる手順（自由に描く B の粗を減らす）

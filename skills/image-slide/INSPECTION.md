# INSPECTION.md — image-slide

> 共通項目は検品する側の基準にある。**ここには固有項目だけ書く。**
> 作成: 2026-10-03。

## 商品の型

**画面型**（スライド）。成果物の実体:

```
<出力先>/deck.pptx               # 本体（全面の絵＋帯の部品＋ノート）
<出力先>/slides/slide-NN.png     # 確認用の絵（帯の部品を焼いたもの）← 検品役が見る
<出力先>/inspect.md              # 検品用の写し（台本の中身・ノート・機械の検査）← 検品役が読む
```

⚠️ **文字は絵の中にある。** PPTX から文字は読めない。検品役は `inspect.md` の「描く文字（台本の中身）」と、絵の中の文字を見比べる。
⚠️ 中身は毎回違う。題材は呼ぶ側が決める。

## 読者

| 読者 | 何ができないと困るか |
|---|---|
| **資料を受け取る人** | 絵を順に見るだけで、話の筋が分かる。絵の中の文字と数字が正しい |
| **話し手** | ノートを読みながら絵を見せれば、話と画面が合う |

## 必須要素（欠けたら失格）

- 台本の全ページぶんの絵がある（`inspect.md` の枚数と `slides/` の枚数が同じ）
- 各ページの見出し（`headline`・`title`）が絵の中にある

## 失格条件（あったら失格）

| # | 失格 | なぜ |
|--:|---|---|
| I-1 | **絵の中の見出し・数字が、台本と違う**（誤字・脱字・別の数字・単位の違い） | 絵の中の文字は直せない。読み手が誤った数字を受け取る |
| I-2 | **台本に無い数字・主張・固有名詞が描き足されている**（吹き出しの「半分になった」のように、台本の言い換えでも新しい語なら指摘する。数字が台本に無ければ失格）。ただし**型の描き方が付ける順番の印**（締め・目次・要約・注釈の「1」「2」「①」）は中身の数字ではないので除く（`scripts/prompt.py` の `PATTERNS` が「番号付きで並べる」と指示している） | 原稿に無い内容を足さないのが製品の譲れない条項 |
| I-3 | **文字化け・意味の通らない文字・英語の穴埋め文**（lorem など）がある | 絵の生成で起きる典型の崩れ |
| I-4 | **グラフの長さ・位置が値と合わない**（大きい値の棒が短い） | 図が嘘をつく |
| I-5 | **下端の帯の部品が読めない**（フッタ・ページ番号が絵と重なって読めない） | 帯の検査をすり抜けた |
| I-6 | **描く指示そのもの**（キーの名前・`**`・`\n`・括弧の注記）が絵に描かれている | 指示文が漏れている |

## 機械で見るもの

`inspect.md` の「機械の検査」に、帯の検査（空いていなかったページと板）が写してある。

## 見ないもの

- 絵柄の好み・ページごとの画風の小さな揺れ（ページを別々に描くので揺れる。読めれば通す）
- 内容の事実の正しさ（題材は呼ぶ側の責任。見本の台本は架空と明記している）
- PowerPoint で開けるか（人が最終確認する）

# 0007 スタイルは standard・visual・カスタム（名前は html-slide とそろえる）

- 日付: 2026-10-05
- 状態: 採用（2026-10-05 に infographic を追記）
- 前提: 層の図を整理した。「デザイン」のような束はやめてスタイルとレイアウトに分け、名前は html-slide と image-slide でそろえる。週報のような形はカスタムスタイルで入れられればよく、その雛形はスキルの中に置く

## 決めたこと

1. **スタイルとレイアウトは別々の引数**。束（「デザイン」など）は作らない。色（`--theme`）・素材（`--ref`・`--logo`）も別。組み合わせるのは呼ぶ側のスキル
   - 理由: 束を作ると、色・素材・追加の注文まで入れたくなり、どの層の話か分からなくなる
2. スタイルは **`--style standard|visual|<YAML>`** の1本。組み込みの名前は html-slide とそろえる
   - `visual`（既定）: ビジュアル寄り。プレゼン・ピッチ向けで、主役を1つに絞り、大きな画像で大胆に見せる（前の `pitch`）
   - `standard`: 説明・報告・社内資料向け。図解とイラストで、文字と図を整理して並べる（前の `business`）
   - 前の名前（`pitch`・`business`）は rc=2 で新しい名前を案内する。`--style-base` は消した
3. カスタムスタイルの YAML は `name`・`description`（補足）・`text`（描く指示に入れる文章）。書式は `scripts/styles.py` の冒頭
4. スタイルへの追加の注文（資料全体の一言）は **`--style-note`**（前の `--style "<文>"`）
5. カスタムレイアウトのファイルには `style` を書かない（書いたら rc=2 で `--style` を案内）。構図と画風を分けて持つ
6. 雛形を `templates/custom-style.example.yaml`・`templates/custom-layout.example.yaml` に置く（週報の例）。製品の棚ではなく、書き方の見本

## 週報での組み合わせ

週報のスキルが2つのファイルを持ち、`--style weekly-style.yaml --layout weekly-report.yaml` で渡す。週報の形を決めているのは主にレイアウト（4段の構図）で、スタイルだけでは4段にならない。

## 追記（2026-10-05）: infographic（1枚に凝縮する）

- standard・visual のほかに、資料全体を1枚に収めるインフォグラフィック（ポスター）のスタイルを足す。週報はそれをさらに指定した形と位置づける
- 組み込みに **`infographic`** を足した。**このスタイルだけは枚数が変わる**: 台本の全ページを「区画」として1枚に描く（`one_page`）。html-slide には無い（image-slide だけ）
- 1枚の描く指示: 全区画の中身（ページごとの型と描く文字）・「全区画を1枚に収める・一番言いたい区画を大きく」・構図は自由（カスタムレイアウトがあればそれ）
- カスタムレイアウトは1枚目の `_layout` が全体に効く（ほかのページに別のレイアウトを書いたら rc=2）。週報は「infographic＋週報のレイアウト（区画を週報の区画に割り当てる）」と位置づけられる
- 参照画像は全ページの画像の枠を合わせて数える（4枚まで）。ページ番号は出さない。ノートは全ページの話す台本を【n枚目】でつなぐ
- カスタムスタイルにも `one_page: true` を書ける
- `poster`（ビジュアル主役の1枚）は、要る資料が出てから。縦長のポスターは、縦横を選べるようにするときに
- 試し（2026-10-05・週報の材料）: infographic だけ・レイアウトなしで3回描くと、毎回ほぼ同じ「上に題と写真、下に3列」の構図になった（区画を資料の順に並べる言い方と、写真の参照画像に引っ張られる）。材料一式として渡し「1枚を最初から設計する・スライドを並べたような見た目にしない」と言うと、大小のついたポスターらしい配置になった。中身が別々の話なので、1つの図への統合まではしない（原稿に無い関係を足すことになる）
- インフォグラフィックは、ただ区画を並べた見た目にしない。infographic の文章と1枚の指示を、上の言い方に直した（区画の番号は、週報のようなレイアウトが区画を割り当てるために残す。番号は並べ方の指定ではない、と明記）

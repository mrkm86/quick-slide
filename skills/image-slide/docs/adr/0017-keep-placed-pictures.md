# 0017 置いた絵を、鍵が合わなくても使う `deck --keep`

- 日付: 2026-10-11
- 状態: 採用

## 決めたこと

`deck --keep <ページ>`（`3,5` / `2-4`）: 区画（キャッシュ）に置いてある `slide-NN.png` を、描く指示の鍵が変わっていても
描き直さずに使う。

- 置いてある絵が無いページは、ふつうに描く
- 鍵（`slide-NN.json` の `key`）は前のまま残す。`--keep` を付けずに流せば、そのときの中身と設定で描き直す
- `--redo` に入れたページは `--redo` が勝つ（描き直す）
- `build.json` のそのページに `kept: true`
- `revise` には無い（revise は、直すページ以外をもともと鍵を見ずに使う）

## 理由

- Quick Slide の「版を選ぶ」は、前の版の絵を区画に置いて組み直す（描き直さない。Quick Slide の `docs/adr/0001-version-pins.md`）
- 鍵は描く指示から作るので、ブランドの色・スタイル・画風が変わると、同じページの中身でも鍵が変わる。鍵が合わないと
  エンジンは Codex で描き直し、画面に出している前の版の絵と、PPTX・PDF の絵が食い違う（新しい版もできる）
- 「この絵を使う」は呼ぶ側が知っている。エンジンは状態を持たないまま、ページ番号で受ける

## 見送ったこと

- 呼ぶ側が、このエンジンがいま作る鍵を求めて、その名前で置く: 鍵の作り方（描く指示の組み立て・参照画像）を呼ぶ側に
  写すことになり、エンジンを直すたびに食い違う
- 置いた絵の鍵（`slide-NN.json`）を書き換えて合わせる: 次に `--keep` なしで流したとき、変わった設定で描き直されなくなる

# 0011 キャラはページごとに台本の `_characters` で渡す。参照画像は Codex の上限の5枚まで

- 日付: 2026-10-06
- 状態: 採用
- 前提: キャラの画像集は、同じキャラでも表情・ポーズを変えて効果的な差し絵にするために作る。だからページごとにキャラを渡せる必要がある
- 比べたもの: キャラの絵を参照画像にして紙面の中に描かせる形（絵を貼り込む形は取り下げた）、
  エンジンがキャラの画像集からポーズを引く形（html-video）、quick-slide の微修正・作り直し

## 決めたこと

1. **台本のページに `_characters` を足す**: `[{"name": "Hana", "image": "<パス>", "pose": "考える"}]`（並べた順が参照画像の順・`pose` は任意）。
   `_` で始まるキーなので html-slide は読み飛ばし、同じ台本が両方のエンジンに通る（ADR 0001）
2. **絵を選ぶのは呼ぶ側。** 用途とポーズに合う絵のパスを書く。
   image-slide はキャラの画像集を知らない（html-video のようにエンジンが引く形にはしない）
3. 描く指示では「参照画像N は Hana（ポーズ・表情: 考える）」と**番号と名前を結び**、造形・顔・服・色・塗りは参照画像のまま、
   中身と関わる位置に置かせる。造形は文章で書かない。置き場所は指定しない（ADR 0005）
4. 参照画像の並びは **画像の枠 → 構図の見本 → `_characters` → `--ref`**。`--ref` は全ページの画風の手本に寄せる
   （キャラを全ページに出したいときだけ `--ref` にキャラを渡す）
5. **透過のある参照画像は白に合成して渡す**（`codex_run._flat_refs`・作業フォルダに写す・元のファイルは触らない）。
   透明のまま渡すと背景が黒く読まれるおそれがある。`--ref` と画像の枠にも効く
6. **1枚に添える参照画像は5枚まで**（`image_slide.MAX_REFS`）。超えたら描く前に rc=2。黙って削らない。
   1枚に凝縮するスタイル（infographic）は全ページのキャラを、同じ絵は1枚にまとめて数える

## 理由

- **5は Codex の画像ツールの上限。** 画像ツールの `const MAX_EDIT_IMAGES: usize = 5;`
  （openai/codex `codex-rs/ext/image-generation/src/tool.rs:59`・`rust-v0.159.2`。2026-05-28 にファイルができてから同じ値）。
  6枚以上は「`referenced_image_paths` must contain at most {MAX_EDIT_IMAGES} paths」で断られる（同 `:438-441`）。
  前の4は理由の記録の無い値だった
- **表情とポーズを変えたい。** 画像集は差し絵のために表情・ポーズを揃えている。`--ref` は全ページ共通で、ページごとに変えられなかった
- **画像の枠を使い回さない。** 枠は「この位置に描く」という置き場の指示を兼ねる。キャラは中身と関わる位置にモデルが置く方が、紙面とつながる
- **名前を付ける。** 番号だけだと、何枚目が誰かがずれて、別のキャラの絵で描く

## 見送ったこと

- 5枚を超えたときに、優先順（土台 → キャラ → 画像の枠 → 構図の見本 → 画風の手本）で削って警告する形。5枚で足りるかを使ってから決める
  - 削る代わりに、キャラを横に並べた1枚にまとめて渡す案を試した（2026-10-07）。2人が出るページを、別々に2枚・1枚にまとめて、の2通りで2回ずつ描いた。まとめた1枚でも、2人とも造形（服・小物・名札）を保ち、名前の札の横にそれぞれが立った（「左が Hana、右が Pochi」と位置で結んだ）。2人・2回ずつでは差は見えない。3人以上で1人あたりの絵が小さくなったときは試していない。
    今は要らないので入れなかった。**5枚を超える場面が出たら入れる**: 両方のエンジンで、超えたときだけキャラを横に並べた1枚にまとめ、「左から Hana、Pochi…」と位置で名前を結ぶ（普段は別々のまま）。入れる前に3人以上で試す
- `--ref` と `_characters` に同じ人がいるときに1枚にまとめる形（同上）
- （同日に入れた → [ADR 0012](0012-revise-minor-remake.md)）今の絵を土台に直す「微修正」と、土台を渡さない「作り直し」（quick-slide の minor・remake）の口。参照画像の役は
  土台（今のページの絵）・素材（キャラ・画像の枠）・手本（画風・構図の見本）の3つに分かれ、作り直しで外すのは土台だけ。
  image-slide は焼く前の絵（`raw/`）を持っているので、土台にはロゴ・番号・透かしの無い絵を渡せる

## 見本（2026-10-06）

週報の材料（5枚・standard）の4枚に、キャラの画像集の絵を渡した（表紙 Hana わくわく・Pochi にっこり／流れ Hana 右を指す／主張 Hana 考える／
カード Hana にっこり・Pochi 調べもの）。

- 4枚とも、画像集の造形（服・小物・名札）のまま描かれた。
  名前を結んだので、カードのページでは Hana の札の横に Hana、Pochi の札の横に Pochi が立った
- ポーズは中身と関わった: 右を指す Hana が流れの4段を指し、考える Hana が主張の横に立った
- 絵の中の文字は台本どおり（見た範囲で誤字なし）
- 微修正と作り直しも同じページで試した（quick-slide の minor・remake と同じ言い方・土台は焼く前の絵）。
  微修正「Hana を右へ・文字を左へ」は、文字・色・札・飾りを保ったまま左右だけ入れ替わった。
  作り直し「黒板にチョークの手描きに」は、文字と Hana の造形を保って画風だけ変わった。
  1回ずつの試しで、ずれの出方を言えるほどの数は描いていない

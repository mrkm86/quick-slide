# 0008 ロゴは html-slide と同じ規則で置く。表紙・写真には帯を頼まず、描いた後に1色の角を測って選ぶ

- 日付: 2026-10-06
- 状態: 採用（2026-10-06 に `--logo-position` を追記）
- 前提: html-slide のロゴ（html-slide の ADR 0007）とそろえる。規則はそろえ、判定の材料（要素か画素か）だけエンジンで変える
- 比べたもの: 幅 12%・右下に固定して角を白く塗る案、幅 9%・四隅を設定で選ばせる案（空けさせない・塗らない・検査しない）、
  quick-slide（右下の枠だけ空けさせて検査）
- 実測: 過去に描いた絵 93 枚（`--logo` なし・`base/`）で右下と左下の 329×44＋周り 16px を測った。
  帯を頼んだ 65 枚は 63 枚が空いていた。帯を頼まない表紙・写真 28 枚は、
  1色の角が右下 0・左下 20・どちらも無い 8（ほぼ全面の写真）

## 決めたこと

1. 寸法は html-slide と同じ: **329×44 の枠に縦横比を保って縮めて収める**（引き伸ばさない）。透明な余白は切ってから収める。
   短辺 30px 未満なら警告。右下は右から 120px、縦は下の文字の行（帯）の中心。ページ番号はロゴの左。帯の左右の余白も 96px から 120px に
2. **帯を頼むのは、帯の部品を載せる本文のページだけ**（`chrome` の型で、ロゴ・フッタ・ページ番号のどれかがある）。
   前は `--logo` があると表紙・章扉・写真にも帯を頼んでいた。全面の絵が下で途切れるのでやめた
3. 本文のページ（帯を頼んだ）: 右下に置き、周りの代表色（帯の色）で**ロゴと同じ大きさの地**を敷く。帯が空かずに板を敷いたページは、板の上の右下
4. 帯を頼まないページ: **右下 → 左下の順に、周りが1色の所**を探し、その色で地を敷いて置く。両方だめなら**置かない**。
   左下の x は本文の余白（120px）。1色 = 周りの画素の 90% 以上が代表色から ±8 以内で、代表色から 40 より離れた画素が 0.6% 以下
5. PPTX では「ロゴの地」（四角）と「ロゴ」（画像）を別の部品にする。結果は `build.json` の `logo.pages` に
   `{no, corner, x, plate}` か `{no, off}`（html-slide の `deck-info.json` と同じ形）
6. 数字（枠・余白・間・警告の閾値・周りの幅）は html-slide の `deck.py` と同じ値を持ち、テストで突き合わせる（`logo_rules_match_html_slide`）

## 理由

- **html-slide と同じ見え方にする。** html-slide は「写真・文字がかかる所には置かない・置いた所には地を敷く」。image-slide は要素が無いので、
  「地を敷ける所（1色の所）にだけ置く」に言い換えた。結果は html-slide と同じ並びになった（表紙は左下・全面の写真は置かない・本文は右下）
- **「平ら」では足りず「1色」にした。** 帯の検査と同じ基準（離れた画素 0.6% 以下）だけだと、表紙のぼけた机の写真の上にロゴが載った
  （2026-10-06 の見本）。html-slide なら写真として避ける場所なので、1色の割合を足して締めた。93 枚では表紙・写真の右下に置くページが 4→0 になった
- **本文のページは1色を問わない。** 帯は検査で空いていると確かめてある。1色を問うと、白い帯に薄い描き込みが残ったページ（3枚）でロゴが消えた。
  地で隠すほうが html-slide の本文（いつも右下）に近い
- **角を白く塗らない。** 写真や色の地の上で白い四角が浮く（見本で確認）
- **四隅を人が決める形にしない。** 角に物が描かれていても重ねてしまう。決めた角を守らせたいブランドが出たら、試す角と順を渡す引数を足す
- **左下を描く前に頼まない（いったん）。** 頼まなくても表紙の左下は多くが空いていた。頼めば絵のモデルの守り方に左右される。
  効き目は表紙・写真を数枚描き直して確かめてから決める

## 見送ったこと

- 両方の角がふさがったページに、白いステッカーで必ず入れる形（html-slide も置かない形なので、そろえて置かない）
- 暗い地での白いロゴの差し替え（html-slide の ADR 0007 と同じく、いったん今のまま）
- 表紙・写真に「下端 7% に文字だけは置かない」と頼む形（上の「左下を描く前に頼まない」）
- 「1色か」の判定を html-slide にも足す（角に飾りの図形やグラデーションがある型で効く。承認済みの4つの資料で見比べてから決める）

## 追記（2026-10-06）: `--logo-position`

html-slide の [ADR 0008](../../../html-slide/docs/adr/0008-logo-position.md) と同じ引数・同じ順にした（`layout.LOGO_POSITIONS`・テストで突き合わせる）。

- `bottom-right`（既定）: 右下 → 左下 → 置かない ／ `bottom-left`: 左下 → 右下 → 置かない ／ `top-right`: 右上 → 右下 → 置かない
- 帯を頼んだ本文のページでは、下の角は帯の中なので測らずに置ける（帯の色で地）。右上と、帯を頼まないページの角は「1色か」を測る
- 左下に置いたページはフッタをロゴの右へ、右下ならページ番号をロゴの左へ寄せる
- 右上は描く前に空けさせていない（測るだけ）。過去の絵（週報の5枚 × standard・visual）では、本文の右上はほぼ空いていた。
  写真の空のように平らな所では、空の色の地で置かれる（html-slide で塗りの面の上に置くのと同じ）。右上へ寄せたいのに右下へ逃げるページが多ければ、
  そのとき「右上の角を空けて」と頼むかを決める

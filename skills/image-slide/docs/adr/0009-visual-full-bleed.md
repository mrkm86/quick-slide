# 0009 visual は本文のページも全面に描かせ、フッタ・ページ番号・ロゴは絵の上に重ねる。ロゴは加工せず、沈む所ではステッカーを敷く

- 日付: 2026-10-06
- 状態: 採用
- 前提: ADR 0008 の見本（visual）で、全面の写真の下に白い帯が残り、見栄えが落ちた。全面の絵は全面のまま描かせて埋め込む
- 比べた案: ロゴの置き方は4つ（白いステッカー・そのまま重ねる・白抜き・右上へ逃がす）。「そのまま重ねる」と「白抜き」の自動切り替えを一度作ったが、
  白抜きはロゴを作り変えることになるのでやめた。別に、何も空けさせず、ロゴは決めた角に、フッタは灰色の文字で中央下に焼く案（読めるかは見ない）

## 決めたこと

1. スタイルに `bleed`（全面に描かせるか）を持たせる。組み込みでは **visual だけ true**。standard・infographic は帯のまま。カスタムスタイルの YAML でも `bleed: true` と書ける
2. bleed のスタイルでは、本文のページにも帯を頼まない。代わりに「絵・写真・背景は端から端まで使ってよい。下端 7% には文字・数字・アイコン・図・カード・グラフを置かない。
   下端の左右の角は落ち着いた背景に」と頼む（`prompt.bleed_clause`）。帯の検査・描き直し・帯の板は無い
3. フッタとページ番号の文字の色は、それぞれの下の明るさで決める（暗ければ白、明るければテーマの文字の色・`compose.area_ink`）
4. **ロゴの画素には手を入れない。** 色を変えない・白抜きを作らない・縦横比を変えない（変えてよいのは大きさだけ。PPTX には原寸 × 倍率で置く）。
   読めるかは、ロゴの明るさと下の明るさのコントラスト比（3 以上・`LOGO_CONTRAST`）で見る
5. 全面のページのロゴは、指定の角の順に: 読める1色の角（同じ色の地を敷く・見えない）→ 読める平らな角（そのまま重ねる）→
   指定の角が読めればそのまま重ねる → 組織の公式の白いロゴ（`--logo-white`・同じ縦横比のものだけ）で読めればそれ →
   どれでもなければ**ステッカー**（ロゴの周りに 12px の余白をとった角丸の地・テーマの地の色）を敷いて指定の角に置く。全面のページでは置かないことはない
6. 帯のある本文のページでも、帯の色が暗くてロゴが沈むならステッカーを敷く。帯の無いページ（表紙・写真）で、沈む1色の角は使わない
7. ページ番号は**既定でオフ**（台本の `page_numbers: true` のときだけ）。出すときは**中央下**（html-slide も同じ）。ロゴは角だけに置くので重ならない。フッタは番号の手前（912px）まで
8. `build.json` の `logo.pages` に、ステッカーは `sticker: true`、公式の白いロゴは `variant: "white"`

## 理由

- 全面の絵に白い帯が残ると、visual の良さ（大きな絵）が消える。帯を頼む必要があったのは、帯の上に部品を「読める状態で」載せるためだったが、
  文字の色とロゴの色を下の明るさで選べば、帯が無くても読める
- 「下の角は落ち着いた背景に」と頼んでも、山の写真では岩が下端まで描かれた（2026-10-06 の3枚・3枚とも下の角がでこぼこ）。
  頼むだけでは角は空かないので、ロゴは置き方で読めるようにする
- **ロゴは組織の顔なので加工しない**（大きさは変えてよいが、色・縦横比は変えない）。白抜きは「そのまま」と「白抜き」の自動切り替えとして一度作ったが、ロゴを作り変えることになるのでやめた。
  変えてよいのは置き場と、ロゴの後ろに敷くものだけ。そのうえで一番絵になじむのは、読める所ではそのまま重ね、沈む所だけステッカー
- 公式の白いロゴは組織が用意した正しい版なので使ってよい。ただし縦横比が違うものは別の版とみなして止める
- ページ番号をロゴの隣に置くと、重ならなくても情報（番号）とブランド（ロゴ）が1か所に寄って落ち着かない。中央下なら、ロゴの角を変えても番号は動かない
- 全面にするかは見せ方（スタイル）の話なので、スタイルに持たせた。週報のような決まった形では、カスタムレイアウトの構図の文章でロゴの角を空けさせればよい

## 見送ったこと

- 表紙・写真（帯の無い型）でも、1色の角が無ければ必ず重ねる形。今は ADR 0008 のまま置かない（html-slide と同じ）
- 文字の影や縁取り（明るさで色を選ぶだけで、見本では読めた）
- html-slide の濃い塗りの面（主張の全面など）で黒いロゴが沈むときのステッカー（html-slide の ADR 0007 の見送りのまま）

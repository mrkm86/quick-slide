# 0003 ロゴ・フッタ・ページ番号は絵に描かせず、PowerPoint の部品として上に載せる

> 2026-10-06: ロゴの大きさ・位置と、帯を頼むページは [0008](0008-logo-same-rules-as-html-slide.md) で改めた（下の 5 の「ロゴだけは全ページに置く」は 0008 が優先。ロゴは1色の角が無いページには置かない）。

- 日付: 2026-10-03
- 状態: 採用（ロゴの大きさ・位置は 0008 が優先）
- 前提: ブランドとフォーマット（ロゴ・フッタ・ページ番号）は、絵の上に機械が合成する（予約した場所を空けさせる）

## 決めたこと

1. 下端の帯（高さ 7%・1920×1080 で 76px）を、描く指示で**1色の無地のまま空けさせる**。帯に載せるもの（ロゴ・フッタ・ページ番号）が1つも無いページでは空けさせない
2. 帯の上には PowerPoint の部品を置く: フッタは文字の枠、ページ番号は**スライド番号のフィールド**（`<a:fld type="slidenum">`）、ロゴは画像。絵には焼かない。確認用の PNG と PDF にだけ焼く
3. 描いた絵の帯を検査する（`compose.band_check`）: 帯の代表色から離れた画素が 0.6% を超えたら「空いていない」。理由（何 % に物があったか）を添えて描き直させ、最後まで直らなければ**地の色の板**を敷いてから部品を載せ、警告する
4. 帯の文字の色は、帯が暗ければ白、明るければテーマの文字の色
5. 帯の有無は html-slide の型の定義と同じ（`cover`・`section`・`photo`・全面の `quote` は帯を出さない）。ロゴだけは全ページに置く

## 理由

- 部品にしておけば、**あとから直せる**（フッタの文言・ロゴの差し替え・並べ替えたときの番号）。絵の資料でも、直せるところは直せるようにする
- 生成に「ロゴを描くな・ここを空けろ」と頼んでも、守られないことがある（quick-slide の 2026-09-20 の実測: 帯を右端まで伸ばす構図が3回続いた）。だから検査して、理由を添えて描き直させる（quick-slide の `clean_area_retry_notice` の考え方）。それでもだめなときに資料が出ないより、板で隠して警告するほうがよい
- 矩形ではなく帯にしたのは、指示が1文で済み、守られやすいから。quick-slide はロゴの位置を設定で選べるが、こちらは帯の中に並べる形に固定した（位置を選べるようにするのは、ブランド・書式を受けるとき）

## 却下した案

| 案 | 却下の理由 |
|---|---|
| ロゴも絵に描かせる（参照画像で渡す） | 形と色が崩れる。ブランドは崩してはいけない側（quick-slide の「保証する層」） |
| いつも帯に板を敷く | 帯が空いているときも板の境目が見える（グラデーションの地など） |
| ページ番号を文字で書く | 並べ替えると番号がずれる |

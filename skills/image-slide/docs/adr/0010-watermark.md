# 0010 透かし（--watermark）は全ページの中央下の端に焼く。フッタか番号があるページは下の行を上げて、下の端を透かしに空ける

- 日付: 2026-10-06
- 状態: 採用
- 前提: 透かしはまず「薄いグレーの文字を中央下に」だけでよい。置き方の見本を作り、下の行を上げる案・色は固定に決めた。
  いったん「透かしを付けたときだけ上げる」にしたが、ページ番号・透かし・フッタの関係が分かりにくいので見直し、
  実際の資料と週報のポスターで見比べて下の 4 に決めた
- 数字: 中央下・`#9ca3af`（Gray-400）・字の高さは画面の高さの 1.5%（1080px で 16px）・ベースラインは下端から 13px（下端から 1.2%）・PNG を保存する前に焼く
- html-slide も同じ日に同じ数字で入れた（html-slide の ADR 0009。数字は `logo_rules_match_html_slide` で見比べる）

## 決めたこと

1. `--watermark <文字>`（check・deck）。台本には書かない。**全ページ**（表紙・写真も）の中央下の端に、16px・`#9ca3af`・
   ベースラインが下端から 13px で焼く（`layout.WATERMARK_*`・`compose.burn_watermark`）。字体はテーマの regular（無ければ游ゴシック R・ヒラギノ W3）
2. 色は固定。下の色は測らない（どの絵の上でも同じ目印に見えるほうがよい）
3. **PPTX の絵にも焼く。** フッタ・ページ番号・ロゴは PowerPoint の部品にするが、透かしだけは絵（`base/slide-NN.watermark.png`）に焼いたまま渡す。
   測る（帯の検査・ロゴの置き場・文字の色）のは焼く前の絵（`base/slide-NN.png`）
4. **下の行（フッタ・ページ番号・ロゴ）は、フッタかページ番号があるページでは上げる。透かしの有無では動かさない。**
   行の中心を帯の中心 1042px から 1026px へ（`layout.row_mid`・`ROW_MID_RAISED`。ロゴ 44px の上端が帯の上端 1004px にそろう）。
   ロゴだけのページ（表紙・写真・フッタも番号も無い週報のポスター）は帯の中心のまま。ADR 0008 の「縦は帯の中心」を、この条件で置き換える。
   下端の置き場は「下の行」と「下の端（透かし）」の2段だけ:

   ```
   [フッタ ………… ページ番号 ………… ロゴ]   ← 下の行（フッタ・番号は本文だけ。ロゴは置ける全ページ）
                 透かし                    ← 下の端（全ページ）
   ```

## 理由

- **帯の中心のままだと番号とぶつかる。** 番号の行は 1031〜1053px、透かしは 1054px あたりから。見本で詰めても（下端から 7px）窮屈だった
- **html-slide と同じ高さ（1021px）には上げない。** ロゴの上端が 999px になり、帯（1004px から）を 5px はみ出す。1026px なら帯に収まり、html-slide との差も 5px で見分けがつかない
- **透かしの有無で動かさない。** 「付けたときだけ上げる」は、部品どうしの関係を読む人がいちばんつまずく条件だった。
  フッタか番号があれば、透かしが無くても上げる（実際の資料の 10 枚で、ロゴの置き場は変わらなかった。standard は行の下が少し空き、html-slide と同じ見え方になる）
- **ロゴだけのページは上げない。** ロゴは角にあり、中央の透かしに届かない。上げると周りの絵や枠にかかる。
  standard の表紙ではロゴが消え、週報のポスターではロゴが近況の枠の文字に触れた（どちらも実物で確認して直した）
- **絵に焼く。** 配布禁止・配布先の目印に使うので、PowerPoint で消しにくいほうがいい

## 見送ったこと

- 斜めの大きな透かし（DRAFT 用）・右上の機密区分のラベル
- 下の明るさで色を変えること（visual の明るい写真の上では薄い。固定で決定）
- 描く指示で透かしの場所を空けさせること（帯・bleed の「下端 7% に文字を置かない」の中に入っている。表紙・写真は頼まない）

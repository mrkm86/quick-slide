# Codex — 認証は1度だけ・並列に描く

画像は Codex CLI の組み込みの画像生成（gpt-image-2）で描く。ChatGPT のサブスク枠で動き、API の従量課金はかからない。
設計の理由は [ADR 0002](../docs/adr/0002-codex-auth-once-parallel.md)。

## 前提

- `codex` が PATH にある（`npm install -g @openai/codex`）。別の場所なら設定の `codex_bin`
- **ChatGPT のアカウントで1度だけログインしておく**: `codex login`（`codex login status` が `Logged in using ChatGPT`）
- `python3 …/image_slide.py auth` で、deck と同じ確認だけを走らせられる

## 1回の実行の流れ

```
deck
 ├─ 使い回せないページを数える（0枚なら Codex も認証も呼ばない）
 ├─ 認証の確認（ここの1度だけ）
 │    ├─ 実ホームの auth.json がある・ChatGPT のログイン（API キーのログインは断る）
 │    ├─ codex login status
 │    └─ トークンが古い（アクセストークンの期限まで3時間未満。期限が読めなければ最後の更新から7日以上）なら、実ホームで1回だけ codex を走らせて更新（codex は期限の5分前まで自分では更新しないので、日数では見ない）
 └─ 並列に描く（既定8本・--parallel・設定の max_parallel）
      各ワーカー: 使い捨ての隔離ホーム（auth.json のコピー・最小の設定）＋空の作業フォルダ
                  codex exec --skip-git-repo-check -s read-only --json [-i 参照画像…] -   ← 指示は stdin
                  <隔離ホーム>/generated_images/ から絵を拾い、隔離ホームごと消す
```

## 守っていること

| | どうしているか | なぜ |
|---|---|---|
| 実 `~/.codex/auth.json` | ワーカーは**コピー**しか触らない。更新が要るときだけ、実ホームで1回・直列に | 並列で同じ refresh token を使うと、奪い合って失効する（`refresh_token_reused` → `token_revoked`） |
| ワーカーの中の更新 | 新しいトークンを配るので起きない見込み。起きたら（コピーが書き換わったら）`build.json` の `auth.worker_refreshed` に数えて警告 | 起きると実ホームのトークンが古くなる。気づけるようにする |
| 課金 | `OPENAI_API_KEY`・`CODEX_API_KEY` を codex に渡さない | 残っていると API の従量課金に切り替わる |
| 取り違え | 隔離ホームはワーカーごとに別 | 共有すると、同時に描いた絵を互いに拾う（別の道具で実際に起きた） |
| ログ | codex の出力はまず隔離ホームの中に受け、**止めた・失敗した・成功したのどれでも**トークン（`auth.json` の値と、JWT・`sk-`・`rt_` の形）を「［伏せた］」にしてから `logs/slide-NN.*` に写す。エラーの詳細も伏せたものから作る | `build.json` と画面とログに秘密を出さない |
| 余計な動き | `-s read-only`・空の作業フォルダ・実ホームの設定（プラグイン・フック・MCP）を持ち込まない | 画像を描く以外のことをさせない。起動も軽い |

## 失敗のとき

| 起きたこと | 振る舞い |
|---|---|
| 認証の失効（`token_revoked` など。**絵が返っていても**） | 残りを止めて rc=4。`codex login` で入り直してから同じ deck を流す（描けたページは使い回す） |
| 枠切れ（429・usage limit） | 全ワーカーを一緒に待たせてから続ける（`retry-after` があればその秒数）。待ちが15分を超えるなら止めて rc=1 |
| 絵が返らない・時間切れ（既定 600 秒。期限を過ぎたら絵が残っていても採らない） | そのページだけ描き直す（`--retries`・既定1回）。それでもだめなら rc=1・PPTX は書かない |
| 帯が空いていない | 理由（帯の何 % に物があったか）を添えて描き直す。最後まで直らなければ地の色の板を敷いて警告 |

## 実測（2026-10-03・Mac・codex-cli 0.159.2）

- 1枚・単独: 38 秒・1672×941（ほぼ 16:9 なので伸縮だけでそろう）
- 見本5枚・並列5: 計 96 秒（1枚あたり 73〜93 秒）。帯は5枚とも空いていた
- サブスク枠は画像で減りが速い（通常の3〜5倍）ので、並列の既定は8にしている

## 失敗の見分け方

失効と枠切れは、**失敗を表す行だけ**から見る（`codex_run.failure_lines`）: `--json` の失敗のイベント（`error`・`turn.failed` など）と、stderr の `ERROR` で始まる行（頭に時刻があってもよい）。警告や反響の中の語（「token_revoked という説明」「429.png」）は読まない。枠切れは `usage limit`・`rate limit`・`429 Too Many Requests` などの形で見て、裸の `429` は根拠にしない。

# 0013 画像の枠は Codex だけで描く（Azure OpenAI の API で描く道は試して見送った）

- 日付: 2026-10-07
- 状態: **見送り。** 一度入れたコードは同じ日に元に戻した
- image-slide の ADR 0014 と同じ判断。測ったこと・入れていたときの形はそちら

## 決めたこと

1. 画像の枠は Codex（ChatGPT のサブスク枠の gpt-image-2）だけで描く（ADR 0011 のまま）
2. **同じ gpt-image-2 でも、呼び方で結果が変わった**（image-slide の ADR 0014 の2）。Azure の同じデプロイを画像の口と会話の口で呼び分けると、
   キャラの取り違えと置き場所が変わった。API で描く道をまた作るなら、会話の口（Responses API の画像生成の道具）で作る

## 測ったこと

html-slide の縦長の枠（1:1.23）を画像の口で1枚描き、1296×1600 で受けた（23.5 秒）。
キャラの無い1枚の絵なので、取り違えの問題はここでは出ていない。

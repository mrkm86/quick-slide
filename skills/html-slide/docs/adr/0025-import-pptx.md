# 0025 既存の PPTX を取り込む（`import` と取り込んだページの型 `html`）

- 日付: 2026-10-13
- 状態: 採用

## 決めたこと

手元の PPTX を、このエンジンの台本にする口 `import` を足す。取り込んだ 1 ページは、決まり（`references/contract.md`）に沿った
絶対配置の HTML をそのまま持つ型 `html` にする。あとは今の道（check → 描き出し → PPTX・PDF・ページの画像、発表の画面の段の再生）に乗る。

1. **`html_slide.py import --pptx <file> --out <フォルダ>`**（`scripts/pptx_import.py`）: `script.json`（`html` 型のページの台本）・
   `media/`（ページの画像）・`theme.yaml`（PPTX のテーマの色と字体）・`import-report.json`（写せなかったもの・近似したもの）を書く。
   状態を持たない・ほかのスキルを呼ばない。依存は今の 4 つ（python-pptx・lxml・Pillow・PyYAML）だけ
2. **型 `html`**（`deck_types.IMPORTED_TYPES`）: キーは `html`（section の中身）・`background`（色か linear-gradient）・`notes`（元のノート）・
   `title`（一覧に出す見出し）。台本を書く側（台本係）の型の一覧・カタログには載せない
   - 画像（`<img src>`）は台本のフォルダからのパスで、組むときに `assets/` へ写す
   - 段は HTML の `data-step`・`data-fx`・`data-delay`。`mode: handout` は段を外し、`steps: false` は段を遅れに直す
   - 書けないもの（rc=2）: `script`・`style`・`iframe`・`a` などの要素、`on…` の属性、`href`、style の `url()`・`@import`、
     `javascript:`、外の URL の画像
3. **取り込んだページ（section の `data-imported`）だけ、止める検査を警告にする**: 文字のはみ出し（字体の違いで起きる）・
   スライドの外へのはみ出し（PPTX ではよくある飾り）。ノートの［クリック］の数は照合しない（PPTX のノートに［クリック］は無い）。
   `render.py`・`verify.py` も、部品 JSON と build.json の `imported` を見て照合を外す
4. **回すだけの transform（`rotate()`）を、取り込んだページの文字の箱にだけ通す。** `extract.mjs` は回さない姿で測り、箱の中心を
   回して PowerPoint の文字の箱の回転（`rot`）に写す。図形は SVG の中で回し、画像は回して焼く
5. **写し方**（`pptx_import.py`・`pptx_text.py`・`pptx_table.py`・`pptx_chart.py`・`pptx_anim.py`・`ooxml.py`・`ooxml_geom.py`）:
   - 1920×1080 に写す。**16:9 でなければ中央に置き、余りは背景で埋める**（単色・グラデーションは全体に、画像は 16:9 を覆う大きさに）。
     元のスライドの外に丸ごと出ている図形は、スライドショーで見えないので写さない
   - マスター・レイアウトの継承（プレースホルダーの位置・文字の書式・背景・飾りの図形・`showMasterSp`）とテーマの色（clrMap・
     lumMod・tint など）を解く。出力の PPTX ではマスターの構造は無くなり、各ページの図形になる
   - 図形はよく使う形を SVG の path に（知らない形は四角にして報告）。四角・角丸は箱（div）に。四角以外のグラデーションは真ん中の色
   - 画像は切り抜き・形の切り抜き・回転・反転・透明度・グレースケールを焼き込む（表示の 2 倍の画素まで。元より大きくしない）。
     EMF・WMF は LibreOffice があれば PNG にし、無ければ空の枠にして報告する。PNG の控えを持たない SVG の画像は、
     このエンジンの Chrome（`scripts/svg_raster.mjs`）でまとめて PNG にしてから加工する（ネットへの読み込みは止める）
   - 字体の名前は PPTX にそのまま書き、画面と PDF では近い字体で描く（太さの付いた名前は太さを外した名前でも探す）。
     英字だけの縦書きは、右へ 90° 回した横書きにする（PowerPoint でも字が横に寝る）
   - 表は 1 セルずつの箱と文字と罫線。グラフ（棒・折れ線・面・円・ドーナツ）は中の数値から SVG で描く。SmartArt は描いた結果の図形
   - アニメーションは開始の効果だけを 8 つの効果に寄せる。クリックの組ごとに 1 段、「同時」「後」は data-delay、段落ごとの効果は段落に段。
     強調・終了・軌跡は写さない（終了の部品は出たまま。あとから出る部品と重なることがあると報告する）。切り替えは fade か none

## 理由

- 位置・色・画像をそのまま持てる。PPTX は今の描き出し係で書けるので、文字も図形も PowerPoint の部品のまま直せる
- 発表の画面（Quick Slide）は、今の html-slide の部品で段ごとに再生できる
- 台本の中に HTML を入れる（ファイルを分けない）と、呼ぶ側の台本の版・複製・戻すの仕組みがそのまま使える

## 見送ったこと

- **型（29 種）に起こし直す**: 見た目が型のものに変わり、「元のとおりに」に合わない。直すときに型で組み直す道は呼ぶ側が持つ
- **ページを画像に焼く**（LibreOffice で PNG）: 見た目は一番近いが、文字を直せずアニメーションも無くなる。配る機体に LibreOffice を要る物にしたくない
- **縦書き（eaVert）を決まりに足す**: PowerPoint の縦書きの文字の箱と、ブラウザの縦書きの位置の読み方が合わない。1 字ずつ縦に並べる列で近似する
- **SVG のグラデーションを部品に足す**: 描き出し係の path にグラデーションの写し方が無い。四角（箱）だけはグラデーションのまま写す
- **終了の効果を決まりに足す**: PPTX の書き出しと発表の画面の両方に要る。使う人と決めて、写さないことにした（2026-10-13）

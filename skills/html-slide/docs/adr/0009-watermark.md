# 0009 透かし（--watermark）は全ページの中央下の端に、固定の薄いグレーで。PPTX では選べない部品にする

- 日付: 2026-10-06
- 状態: 採用
- image-slide も同じ日に同じ数字で入れた（image-slide の ADR 0010）

## 決めたこと

1. `deck --watermark <文字>`。台本には書かない（ロゴと同じく引数。同じ台本を配る先ごとに違う透かしで出せる）。1行だけ（改行は rc=2）
2. **全ページ**（表紙・章扉・写真も）の中央下の端。16px・`#9ca3af`・ベースラインが下端から 13px（`deck.py` の `WATERMARK_*`・
   `templates/deck.html` の `.watermark`。Yu Gothic で箱の上端 1054px のときベースラインが 1067px になるのを Chrome で測った）
3. 色は固定。下の色は測らない（明るい写真の上では薄くなるが、透かしなので目立たない薄いグレーのままでよい）
4. 下の文字の行（1006〜1037px）の下に入るので、行は動かさない（ページ番号を出すと、番号の下に透かしの2段になる）
5. PPTX では各スライドに `!!watermark` の文字の部品を置き、`a:spLocks`（noSelect・noMove・noResize・noRot・noTextEdit・noGrp）を付ける。
   クリックで選べず、うっかり動かしたり消したりできない。消すには［選択］ウィンドウから

## 理由

- **ページ番号と重ねない。** 番号も中央下なので、2段にした。html-slide は行（1006〜1037px）と下端の間に 30px あるので、行を動かさずに入る
- **マスターにもフッタの枠にも置かない。** マスターの部品はスライドの部品より下に描かれ、全面の写真のページでは隠れる。
  「ヘッダーとフッター」の枠も、置く位置はレイアウトが決め、写真の下になるのは同じ。全ページで見えることを優先して、スライドごとの一番上の部品にした
- **選べない部品にした。** 配布禁止・配布先の目印に使うので、普段の操作では消えないようにする。完全には防げない（［選択］ウィンドウや XML からは消せる）。
  消されたくなければ image-slide（絵に焼く）か PDF で配る

## 見送ったこと

- 斜めの大きな透かし（DRAFT 用）・右上の機密区分のラベル（まず中央下の1つだけにした）
- 下の明るさで色を変えること（固定で決定）
- PowerPoint で開いたときに選べないことの確認（PowerPoint の画面は操作しない約束。XML に spLocks が入っていることだけテストで見ている）

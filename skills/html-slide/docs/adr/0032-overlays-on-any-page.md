# 0032 どの型のページにも、絵を重ねられる（`overlays`）

- 日付: 2026-11-20
- 状態: 採用
- 関係: ADR 0025（PPTX の取り込み。取り込んだページは HTML に画像を足せる）・ADR 0030（自由なページ）

## 背景

型のページに絵や写真を入れるには、画像の枠を持つ型・変化形に替えるしかなかった。表のページに絵を足すと箇条書きに替わり、
写真のあるページに絵を足すと写真が置き換わる。使う側が望むのは「いまのページに、絵が加わる」こと。

## 決めたこと

1 枚に共通のキーに **`overlays`** を足す。ページの座標（1920×1080）に置く画像の並びで、型の中身は変えない。

- 1 つずつ `{"x", "y", "w", "h", "image": {"path": …}, "fit"?}`。`fit` は `cover`（既定）か `contain`
- 画像は持ち込みのファイルだけ（生成の枠・SVG は書けない。呼ぶ側が先に画像にして `path` で渡す）。**台本のフォルダの中の
  ファイルだけ**（相対パスで書く。絶対パス・外を指すパス・外を指すリンクは rc=2。書き出しに、関係のないファイルを巻き込まない）
- 型の中身の上、下の文字・ページ番号・透かしの下に置く（`<div data-name="重ねた絵">` に `<img>` を絶対配置で並べる）。
  PPTX には、ふつうの画像として入る
- 検査（rc=2）: 配列でない（`null` も）・知らないキー・数でない座標（文字の数・真偽も）・幅か高さが 40 未満・ページからはみ出す・`fit` の値・画像が無い・URL・
  台本のフォルダの外・8 個を超える
- 型の中身の組み方（見出しの大きさ・中身の広げ方）は、重ねても変えない（重ねた絵を「画像のあるページ」に数えない）
- **どこが空いているかは、エンジンは見ない**（文字に重なる位置でも通す）。空きを見て位置を決めるのは、呼ぶ側の仕事
  （描いた結果の部品 `parts.json` に、文字・画像・図形の位置がある）

## 理由

- 型ごとに「絵の枠」を足すと、型の数だけ置き方を決めることになる。重ねる絵は型に関係なく同じ仕組みで置ける
- 取り込んだページ（型 `html`）は、もう同じことを HTML への追記でしている。型のページにも同じ道を用意する

## 却下した案

| 案 | 却下の理由 |
|---|---|
| 型ごとに、任意の画像の枠（`side_image` など）を足す | 型の数だけ置き方が要る。表・グラフ・自由なページには置き場が決めにくい |
| エンジンが空きを探して自動で置く | 組む前には文字の位置が分からない（描いてから測る）。位置を決めるのは、描いた結果を見られる側 |
| `overlays` に生成の枠（`prompt`）を書けるようにする | 枠の大きさと画風の扱いが、型の画像の枠と別に要る。呼ぶ側が先に描けば足りる |

## 残したこと

- ページを直して中身の位置が動いたとき、重ねた絵が文字に重なっていないかの検査
- 段（クリックで出す）への参加。いまは、ページに入ったときから出ている

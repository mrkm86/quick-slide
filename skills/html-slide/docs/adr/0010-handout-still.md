# 0010 mode: handout は動きのない資料にする（効果も切り替えも付けない）

- 日付: 2026-10-06
- 状態: 採用
- 資料だけ作りたい（動きの要らない）使い方に、新しいオプションを足さず、今の handout を変えて応える。
  時間・動きの層の方針は PowerPoint らしく動かすこと。image-slide は時間・動きの層を持たない

## 決めたこと

1. `mode: handout`（`--mode handout`）では、**出方の効果も画面の切り替えも付けない**。全部が最初から出ている。
   HTML に data-step・data-fx・data-delay を書かず、`data-transition="none"`。PPTX に `p:timing`・`p:transition` が入らない
2. ノートは今までどおり `talk` を改行でつなぐ（［クリック］は入れない）。`talk` の数の照合は talk モードと同じ（同じ台本を両方で使えるように）
3. mode の値は talk・handout の2つのまま（「話すか、配るか」）

## 理由

- **前の handout（段の順に 600ms ずつ自動で出る・切り替えはフェード）は、発表にも読む資料にもなりきっていなかった。**
  1枚ずつめくって読むと毎ページ待たされ（表紙は6段で約 3.6 秒）、受け取った人が直すときはアニメーションのウィンドウに効果が並んで邪魔になる。
  印刷・PDF では最後の状態しか出ないので、動きの得は無い
- **値を足さずに変えた。** 前の handout を使っているスキルは無かった（html-slide の中だけ）。「配るが自動で動かしたい」使い方は思い当たらない

## 見送ったこと

- 3つ目の値（前の handout の形を残す `static` など）。要る使い方が出たら足す

# 0027 メタファイルを画像枠と同じページで PNG にする

- 日付: 2026-10-16
- 状態: 採用
- 関連: #26・0025-import-pptx

## 判断

EMF・WMF を直接 PNG に変換せず、画像枠と同じ寸法の Draw のページに埋めた一時 FODG を変換する。
ページも画像も原点から同じ幅・高さで配置し、余白を足さない。FODG の入力フィルターを明示する。
表示寸法の2倍（長辺4096画素まで）で描く。背景は従来の直接変換と同じ白にする。
同じ素材・寸法のラスタライズは共有し、全ページ分を1回の LibreOffice 起動で一括変換する。
配置ごとの変換では、繰り返し配置された図のたびにプロファイル作成と起動を待つため、数分かかる。
その後の srcRect・マスク・回転・反転は既存の画像処理に任せる。

## 理由と却下した案

合成した200×100の EMF を直接変換すると、794×1123画素の A4 ページの中央に原寸の図が置かれた。
後段がそのページ全体を画像枠に縮めるため、図の本体が極端に小さくなる。
白や透明の画素を探して切り詰める案は、元画像の意図的な余白や PPTX のクロップの基準を壊すので採らない。
EMF のヘッダーから座標を推定して PNG を切る案も、変換器が追加したページと図の座標の対応に依存するので採らない。

## 検証

試験中に生成する赤い矩形の EMF を PPTX に埋め、実際の LibreOffice で変換する。
画像枠の画素数・元の10%の余白・srcRect によるクロップ・同じページの通常の PNG を確認する。
同じ画像のクロップ違いを含めても変換は1回で、入力も1つにまとまること、変換器が無い場合の枠と報告も確認する。
LibreOffice が無い環境では実変換だけをスキップする。実資料は試験に含めない。

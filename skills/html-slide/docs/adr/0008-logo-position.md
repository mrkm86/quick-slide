# 0008 ロゴの角は右下・左下・右上の3つから選べる。ふさがれば決まった1つ先へ逃がす

- 日付: 2026-10-06
- 状態: 採用（ページ番号の位置は下の追記で変えた）
- ADR 0007 の右下 → 左下を、引数で選べる形に広げた。image-slide も同じ引数を持つ（image-slide の ADR 0008 の追記）

## 決めたこと

1. `deck --logo-position bottom-right|bottom-left|top-right`（既定 bottom-right）。左上は持たない
2. 試す順は、指定の角 → 決まった1つ先 → 置かない
   - bottom-right: 右下 → 左下（ADR 0007 と同じ）
   - bottom-left: 左下 → 右下
   - top-right: 右上 → 右下
3. 右上の位置は、右は 120px、縦は上の余白の中（中心 46px・44px のロゴで 24〜68px）。見出し（`.head`）は 80px から
4. 左下に置いたページは、下の文字（footer）をロゴの右へ寄せる。右下ならページ番号をロゴの左へ。右上ならどちらも動かさない
5. 角ごとに部品の名前を変える（`!!logo`・`!!logo-left`・`!!logo-top`）
6. 置き場を測るとき、下の文字とページ番号は隠して、かかるものに数えない（ロゴの角に合わせて動かすので）

## 理由

- **上下をまたいで逃がすのは、右上 → 右下だけ。** ページごとにロゴが上に行ったり下に行ったりすると、資料全体で落ち着かない。
  右の列のまま上下するだけなら目が追える
- **右上から左下までは逃がさない。** 右に置くと決めた資料で、ロゴが斜めの角へ飛ぶのは指定の意図から外れる
- **左上は持たない。** 見出しの書き出しの場所で、ロゴと読む順がぶつかる
- 見本の資料（22枚）で: 右下と左下はほぼ全ページ指定の角、右上は右半分が絵の表紙・章扉と全面の写真で置かない

## 見送ったこと

- 右上を選んだときに、表紙で左下へ逃がす形（右上も右下も絵の表紙では、ロゴが無くなる）。必要になったら逃がし先を足す

## 追記（2026-10-06）: ページ番号は既定でオフ・出すときは中央下

- ロゴとページ番号が同じ角にあると、重ならなくても落ち着かない。既定をオフにし、出すときは中央下に置く
- 台本の `page_numbers` の既定を `false` にした（image-slide も同じ）。出すときは `.pageno` を中央下（900〜1020px・中央そろえ）に置き、
  下の文字は番号の手前（912px）まで。ロゴは角だけに置くので、ロゴの角を変えても番号は動かない。前の「ページ番号をロゴの左へ寄せる」はやめた
- ロゴは加工しない（色・縦横比を変えない。image-slide の ADR 0009）。html-slide はもともとロゴの画像をそのまま置いている

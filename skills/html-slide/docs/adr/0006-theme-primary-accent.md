# 0006 テーマの色は主役の色（primary）と差し色（accent）。既定は白・チャコール・シアン

- 日付: 2026-10-05
- 状態: 採用
- image-slide も同じテーマの形を受ける（image-slide の `themes/`・`scripts/script_io.py`）

## 決めたこと

1. テーマの YAML は `background`・`ink`・`primary`（必須）と `accent`（差し色・任意）。`muted`・`surface`・`font`・`font_files` は今までどおり任意
2. **強調は3つの層で決まる。** どこを＝台本（`*語*`・`accent: true`）／どう＝スタイル（淡い地に枠・ベタ塗りに白抜き）／何色で＝テーマ。色の引数は `--theme` だけ（`_color` のような引数は作らない）
3. 振り分け:
   - `primary`（骨格）… 上の帯・表紙の線・小見出し・目次の番号・章扉・主張の縦線と全面・大きな数字・箇条書きの印と番号の丸・矢羽根の地・連絡先・注釈の丸印・体制の役割
   - `accent`（差し色）… `*語*`・強調するカード／比較の列／KPI・強調する棒と線・年表の強調・表の強調する列・吹き出し・四象限の強調・矢羽根の強める段
4. `accent` を書かなければ `primary` と同じ色（1色のブランドは今までと同じ見た目）。既定のテーマはこれ
5. 2色それぞれから、面・文字（読める濃さに暗くする）・文字を載せる面・その面に載せる文字（白か文字の色の読める方）・淡い地・写真の上の色を作り、全部の組み合わせのコントラストを検査する
6. 古い書き方（主役の色を `accent` に書く）は rc=2（「primary に名前が変わった」）。組み込みの3つ（default・forest・warm）は書き換えた
7. 既定（`themes/default.yaml`）は白の地・`#404040`（チャコールの文字）・`#0db4f2`（シアンの主役の色1つ）。白の上で文字が読め、シアンの面は白抜きで読める。**エンジンには組織の名前のプリセットを置かない**。組織の色は使う側がテーマの YAML を持つ
8. 3色で表せないもの（罫線・見出しの飾り・角の丸み・グラフの色の順番など）は、要るとわかったら**決まった項目**としてテーマに足す（両方のエンジンで効くように）。文章で書く受け口は作らない（html-slide では効かないため）

## 理由

- 1色で骨格と強調を兼ねるブランド（白 × チャコール × シアン ＋ グレーなど）は、1色の形のままでよい
- 主役の色と差し色を分けるブランド（例: 黄色が主役で、青は小面積の差し色）は、1色では青が消えるか黄色が消える。黄色は白の上で文字として読めず、強調語が暗い茶色になっていた
- 3色を超える自由記述（罫線・見出しの飾りなど）は、今は足さない。要るとわかったものから決まった項目にする

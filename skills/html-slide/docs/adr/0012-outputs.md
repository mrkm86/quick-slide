# 0012 出力は PPTX・PDF・ページの画像・サムネイルの4つ（--format で選ぶ・クリップボードはエンジンに入れない）

- 日付: 2026-10-07
- 状態: 採用
- 求めたこと: PPTX と PDF を両方出す／ページごとの画像が明示的に得られる（週報・月報では PDF・PPTX は要らず、画像だけ欲しいことがある）／できた資料をサムネイルでざっと見たい
- 前の形: PPTX と `slides/slide-NN.png`（確認用の扱い）だけ。PDF は無かった（image-slide は PPTX・PDF・確認用の PNG）

## 決めたこと

1. **出力は4つ: `pptx`（deck.pptx）・`pdf`（deck.pdf）・`png`（slides/slide-NN.png）・`thumbs`（thumbs.png）。** `--format pptx,pdf,png,thumbs` で選び、省けば4つとも。
   入口の名前・語・置き場は image-slide と同じ（image-slide の ADR 0013）。前の `--no-png` は残す（`--format` から png・thumbs を外すのと同じ）
2. **PDF は `deck.html` を Chrome で印刷する**（`snapshot.mjs --pdf`）。1ページ = 1 section、PPTX と同じ 13.333×7.5 インチ（1920px を 2/3 に）。文字は選べて検索でき、字体は埋め込まれる。
   不透明な PNG の写真は JPEG（品質 88・長い辺 2560px まで）にした写しで印刷する（PNG のままでは 10枚で 30MB、JPEG にして 2.2MB）。透過のある絵（ロゴ・切り抜き）は PNG のまま。
   LibreOffice で PPTX を PDF にする道は取らない（字の詰まり・図形の描き方が PowerPoint とずれる）
3. **ページの画像は「確認用」から「渡せるもの」にする。** 1920×1080、ロゴ・フッタ・透かし込み、クリックで出るものは全部出た形。ページを減らしたら、前の回の余ったページの画像は消す
4. **サムネイルは全ページを 480×270 に縮め、「番号 見出し」を添えて4列に並べた1枚。** 16ページを超えたら `thumbs-01.png`・`thumbs-02.png` …（前の回の分は消す）。
   見出しは台本の headline・title・quote・value の順に拾う。並べ方は catalog の一覧画像と同じ部品（`outputs.py`。image-slide と同じファイルで、テストが見比べる）
5. **クリップボードには入れない。** 呼ぶ側の仕事にする
   - エンジンは無人でも動く（チャットや定期実行から流すと、クリップボードは誰の手元にも無い）
   - クリップボードに入るのは1枚だけで、「何枚目を」は画面の側で選ぶもの
   - エンジンは決まった置き場にファイルを置き、`deck-info.json` の `outputs` に載せるところまで。会話の中で頼まれたら、呼ぶ側が
     `osascript -e 'set the clipboard to (read (POSIX file "<…>/slides/slide-03.png") as «class PNGf»)'`。クイックスライドを作り直すなら、そちらのオプションにする
6. 作れなかった出力（Chrome が動かないなど）があれば rc=1。PPTX を作らないときは照合（verify）と inspect.md も作らない

## 理由

- **週報・月報は画像で貼る。** PPTX を開いて書き出す手間を省く。`--format png` なら PPTX を組む工程も飛ぶ
- **PDF を HTML から作れば、ページの画像と同じ見た目になる。** 同じ HTML から撮るので、PDF と PNG が食い違わない。PowerPoint で開いた PPTX とは改行がわずかにずれることがあるが、PNG にも同じずれがあり、前からの引き換え
- **サムネイルは安い。** 撮ったページの画像を縮めて並べるだけで、1秒もかからない。既定で作ってよい

## 見本（2026-10-07）

10枚・visual・photo の台本を `--no-fill` で組んで、4つで 8.7 秒。PDF 2.2MB（960×540pt・10ページ・游ゴシック埋め込み）、サムネイル 2072×1210。

## 見送ったこと

- 倍の解像度のページの画像（3840×2160）。html-slide だけなら撮れるが、image-slide は元の絵が 1672×941 で意味が無い。要るとわかったら `png` の選び方として足す
- クリックごとの画像（talk の段ごとに1枚）。週報・月報の用途では要らない
- PDF にノートのページを付ける

# 0014 描いた絵はキャッシュに置く（台本のそばに置かない・assets/ は張る）

- 日付: 2026-10-07
- 状態: 採用（macOS 版。Windows・Linux はロードマップ）。ADR 0011 の 4.（置き場 `images/gen-<鍵>.png`）を置き換える。キャッシュの場所は ADR 0015 で `~/Library/Caches/quick-slide/html-slide/` に変えた
- image-slide の ADR 0015 と同じ判断（測った数字はそちら）

## 決めたこと

1. **Codex で描いた生成の枠の絵（`gen-<鍵>.png`・横の `.json`）と直す前の絵（`history/`）は、キャッシュの区画に置く。** 区画は台本のフォルダごと。
   鍵の作り方（ページ番号を入れない・ADR 0011）は変えない。置き場は `~/Library/Caches/html-slide/`。環境変数 `HTML_SLIDE_CACHE` か設定の `cache_dir` で変えられる。
   区画の場所は `deck-info.json` の `cache`
2. **上限と消す順は image-slide と同じ**（`scripts/cache.py` は同じファイル。テストがバイト単位で見比べる）。設定の `cache_max_mb`（既定 1024 MB・0 は消さない）
3. **出力フォルダの `assets/` には、区画の絵をハードリンクで張る。** 同じ絵で場所を二重に取らない。張れないとき（別のボリューム）は写す。
   張る前に前の回のファイルを消す（前の回の張りに書き込むと、区画の絵が書き換わる）
4. **前の置き場（台本のそばの `images/gen-<鍵>.png`）にある絵は、区画へ写して使う。元は消さない。** 台本のフォルダは人の持ち物
   （持ち込みの絵 `images/s{NN}-{枠}.png` も同じフォルダにある）なので、スキルは消さない
5. 気に入った生成の絵を残したいときは、持ち込みの置き場（`images/s{NN}-{枠}.png`）に写すか、台本の `path` に書く。持ち込みはキャッシュの上限で消えない

## 理由

- image-slide の ADR 0015 と同じ。加えて、html-slide は描いた絵を台本のそばと `assets/` の2か所に持っていた（`assets/` は合計 124 MB）
- `.json`（何から描いたか）は絵の横に残すので、呼ぶ側の DB が拾える形は変わらない（場所は `deck-info.json` の `cache` で分かる）

## 実物での確かめ（2026-10-07）

10枚・生成の枠9つの台本（絵は前の置き場）を、台本と `images/` ごと一時フォルダに写して流し直した。Codex は呼ばず、9枚とも区画へ写って PPTX まで組めた（verify=OK）。
`assets/` の9枚は全部、区画の絵と同じ i-node（ハードリンク）。

# 0007 ロゴは右下の固定の枠に縮めて収め、そのページの地の色で地を敷く。写真がかかれば左下、両方だめなら置かない

- 日付: 2026-10-05
- 状態: 採用（角の選び方は [ADR 0008](0008-logo-position.md) で広げた）
- 比べた案: 幅の割合で大きさを決めて右下に固定し、角まで白く塗る案／幅の割合で決めて四隅から選び、塗らない案／
  固定の枠（329×44）に縮めて収めて右寄せにする案（quick-slide の `placement.py`）

## 決めたこと

1. 受け口は `deck --logo <PNG か JPEG>`。台本には書かない（image-slide と同じく引数。台本に足すと片方のエンジンで止まる）
2. 大きさは **329×44 の固定の枠に縦横比を保って収める**（quick-slide と同じ寸法）。縮めるだけで引き伸ばさない。透明な余白は切ってから収める。短辺が 30px 未満なら警告
3. 位置は右下。右は本文の余白（120px）、縦は下の文字の行の中心。ページ番号はロゴの左へ寄せる
4. ロゴの後ろに**ロゴと同じ大きさの地**を敷く（PPTX では別の部品 `!!logo-plate`）。色は、組んだ HTML を Chrome で開いて測る、ロゴの周り 16px で一番多い色（`scripts/logo_ground.mjs`）
5. 右下に写真・絵（`<img>`）か文字がかかるページは**左下**に置き、そのページの左半分の文字の左端にそろえる。左下もふさがれば**置かない**
6. 左下のロゴは別の名前（`!!logo-left`）。同じ名前だとモーフで右下へ滑る

## 理由

- 幅で決めると、正方形に近いロゴが大きくなりすぎる（幅の割合で決める形では、正方形に近いロゴが 230×141・画面の高さの 13% になった）。高さに上限を置けば形が違ってもそろう
- 地をテーマの地の色で塗ると、地の色が違うページ（主張の全面・章扉・表紙の面）で四角が浮いた（2026-10-05 の見本で確認）。型ごとに色を書き分けると、型23種とカスタムのスタイルに追いつかない。組んだ結果を測れば、どの型でも同じ規則で済む
- 写真の上に地を敷くと四角が浮き、敷かなければ写真によってはロゴが読めない。写真は色ではなく要素で判定する（まだらな色の判定より確か）

## 見送ったこと

- 暗い地での白いロゴの差し替え（quick-slide の `LOGO_VARIANTS` の考え方）。既定の色の visual の締め（`#097ea9`）では黒いロゴが弱いが、いったん今のままにした
- 全面の絵の上でも、地が平らな所なら置く形
- 四隅を選ぶ引数（→ [ADR 0008](0008-logo-position.md) で右下・左下・右上の3つから選べるようにした）

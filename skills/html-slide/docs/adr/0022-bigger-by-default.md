# 0022 余白のあるページは大きく組む（見出しと grow を広げる）

- 日付: 2026-10-10
- 状態: 決定

## 背景

デジタル庁デザインシステムに沿わせた後（ADR 0020・0021）、同じ原稿で台本から作り直して前の版と並べた。土台（色・枠・字）は整ったが、本文の文字はほとんど大きくならず、下の余白が残るページが多かった。

調べると、grow（ADR 0018）は動いていたが、次の3つで頭打ちになっていた。

- 採る条件が「上げた後も置ける高さの 7 割以下」で、もともと 6〜7 割埋まっているページは一段も上がらない
- 上る段は 2 つまでで、28 → 36 の差しか出ない
- 役の上限（本文 36・箱の題 45）

見出しは図解の型（equation・hub・pairs）だけが 80 で、ほかは 64 だった。

## 決めたこと

1. **見出し**: 画像のないページは、80 で1行に収まる見出しを 80 にする（`Slide.big_head`）。2行になる見出しは今までどおり 64 から（2行の 80 は本文の場所を削るため）。80 で中身が入らなければ、今までの見出しで組み直す
2. **grow の条件を2つに分ける**: 置ける高さの 8 割（`GROW_FILL`）に届かなければ試し、上げた結果が 9 割2分（`GROW_MAX`）までに収まる一番大きい段を採る
3. **上る段は 4 つまで**（`GROW_STEPS = (4, 3, 2, 1)`）
4. **役の上限を上げる**: 箱の題 45 → 57・本文 36 → 45・用語と説明 45 → 57（`skills/dads/tokens/slide.json` の `roles` も同じ）
5. **どれかの役が元より小さくなる段は採らない**: 題が上がった分、本文が下がる組み方（箇条書きで題 57・本文 24 になった）を防ぐ
6. 用語と説明（deflist）の用語の列の幅は、組む大きさで測って格子の 3〜5 列から選ぶ
7. 見出しの下限を 45 から 48 に上げる（本文の上限 45 と同じにならないように。見出しは常に本文より大きい）

## 採らなかったこと

- 2行の見出しも 80 にする: 本文の文字が下がるページが出る
- 表・グラフ・お知らせの枠を grow の対象にする: 表とグラフは行や軸の数で高さが決まり、お知らせの枠は中身が 8 割埋まっていた

## 追記（2026-10-10）残りの型にも広げた

`GROWABLE` に 表（table）・棒グラフ（bar-chart）・折れ線（line-chart）・指標（kpi）・大きな数字（big-number）・放射（hub）・式（equation）・対（pairs）・手順（steps）・2×2（matrix）・体制（team）・目次（agenda）・引用（quote・文字だけ）を足した。お知らせ（notice）は箱の内側の上下の余白を 32 → 24 にして、文字が上がるようにした。画像のあるページは今までどおり大きくしない。
型は `s.need`（中身の見積もった高さ）と `s.avail` を出し、文字は `s.g(基準, 上限)`、行・箱の高さと余白は `s.gap()` で 8 の倍数のまま広げる。上限は次のとおり（基準 → 上限。`slide.json` の `roles` は表のセルだけ 28 → 45 に直した）:

| 型 | 上る文字 |
|---|---|
| table | セル・見出しのセル 28 → 45（行の高さの上限 112 → 168 まで） |
| bar-chart | 値 36 → 45・名前 28 → 32・棒の太さの上限 160 → 240 |
| line-chart | 値 28 → 36・時点 28 → 32・線の名前 28 → 32・線は 2px 太く |
| kpi | 数字 3 つは 96 → 120・4 つは 80 → 96・ラベルと増減 28 → 36・注記 22 → 28 |
| big-number | 説明 36 → 45・補足の数字 57 → 64・補足の文 28 → 36（主役の数字は元から 200） |
| hub | 題 36 → 45・補足 24 → 32・札 22 → 28・箱の高さ 200 → 232 |
| equation | 題 45 → 64（答えは 57 → 64）・補足 26 → 36・アイコンの丸 128 → 192・箱の背が伸びる |
| pairs | 文 28 → 32（2 組を縦に並べたときは 45）・名札 36 → 45。2 組は大きく組むとき縦に 2 つ（横だと箱が狭くて文字が上がらない） |
| steps | 題 36（5 段は 32）→ 45・補足 28 → 36・縦の段の間隔 40 → 56 |
| matrix | 点の名前 28 → 36・象限の名前 28 → 36・軸 26 → 32 |
| team | 名前 36 → 45・役割と一言 28 → 36・頭文字の丸 160 → 240 |
| agenda | 項目 45 → 57・行の高さ 136 → 204 |
| quote | 引用 57 → 80・肩書き 32 → 36 |

「行や項目の数」で高さが決まる型（棒グラフ・折れ線・2×2）は、高さを使い切って描くので、`need` を「項目の数 ÷ 8（折れ線は時点の数 ÷ 12）」の割合にした。横に詰まっていない（項目が少ない）ときだけ上がる。表は `s.fit` の役（`table-th`・`table-td`）で同じ大きさにそろえる。
式の箱の幅は、丸めた `px()` でなく小数で書いた（4 つの要素と答えの幅が丸めで 2px 越え、描き出しの検査が止まっていた）。

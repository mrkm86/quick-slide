# 0018 中身が少ないページは大きく組み、並ぶ項目の文字の大きさはそろえる

- 日付: 2026-10-09
- 状態: 採用

## 決めたこと

1. 並びの型（cards・flow・compare・bullets・closing・timeline・summary）は、組んだ中身の高さを見積もる（`Slide.need`）。
   置ける高さ（見出しの下から中身の下端まで）の 70% に満たなければ、文字と間隔を 1.25 倍・1.15 倍の順に大きくして組み直し、
   70% に収まる一番大きい倍率を採る。どれも入らなければ元のまま
2. 画像のあるページは大きくしない（画像の枠の大きさが変わると、描いた絵の区画が変わるため）
3. 並ぶ項目の同じ役の文字（カードの題・本文、矢羽根の題 など）は、大きさをそろえる。1つでも縮んだ項目があれば、
   その大きさを上限にして全部を組み直す（倍率 1 のときも効く）
4. 大きく組むとき、本文は題との元の比（倍率 1 のときの大きさの比）より大きくしない（題が長くて縮んだのに本文だけ大きくなるのを防ぐ）
5. 台本には何も足さない。型が決める

## 理由

- 項目が2〜3個のページで、中身の下に大きな空きが残り、資料全体が同じ薄い見た目になっていた
- 文字の大きさは型ごとに固定で、項目ごとに縮めていたため、隣り合うカードの題が 55px と 45px のように不ぞろいになることがあった

## 見送ったこと

- 箱を引き伸ばして場所を埋める形。中身の少ない大きな箱は、空きが箱の中に移るだけで見た目が良くならない
- ブラウザで測ってから組み直す形。資料を組むたびに Chrome を開くことになり、純ロジックの試験も遅くなる。見積もりは文字の幅を
  字体から測るので、行数は合う（ずれても `check` のはみ出しの検査が止める）

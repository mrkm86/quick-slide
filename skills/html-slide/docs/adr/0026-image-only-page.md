# 0026 photo の全面に hide_text（画像だけの扉絵。見出しはページの名前として持つ）

- 日付: 2026-10-14
- 状態: 採用

## 背景

「表紙を画像だけにして。文字も幕もいらない」と何度頼んでも、台本係は題の 1 行を残すしかなかった。`cover` も `photo` も
見出しが必須で、全面の写真には文字を読ませるための半透明の幕が付く。画像だけのページを書く手段が型に無かった。

## 決めたこと

- `photo` の `layout: full` に `hide_text: true` を書くと、画像を全面に敷くだけのページにする（幕も文字も出さない。
  クリックの段は無い）。**`headline` はこれまでどおり必須**で、ページの名前として持つ（一覧・版の履歴・修正の欄に出る。画面には出ない）
- `caption`（出典）だけは書ける。右下に小さく、文字の後ろだけ暗くして出す（他人の画像を使ったときの出典のため）
- `hide_text` は `layout: full` だけ（`left`・`right`・`band` は文字の欄があるので使えない）
- `cover` は題が要るまま（資料の題を持つ型）。画像だけの表紙は、1 枚目をこの `photo` にする（`references/deck-format.md` に書いた）

## 理由

- 扉絵・章の区切りの写真・印象だけのページは、資料ではよく使う
- 型を増やすより、全面の写真の見出しを省けるようにする方が、台本を書く側の覚えることが少ない

## 却下した案

| 案 | 却下の理由 |
|---|---|
| `cover` の題を省けるようにする | 資料の題を持つ型で、表紙の書き出し（PPTX の題など）が題を前提にしている |
| 画像だけの型を新しく足す | `photo` の全面と見た目が同じで、型の一覧が増えるだけ |
| `photo` の全面の `headline` を省けるようにする | 一度そうしたが、ページの名前が消えて一覧に型の名前（photo）が出た。題は変えずに、出さないだけにする（利用者の指摘・2026-10-14） |

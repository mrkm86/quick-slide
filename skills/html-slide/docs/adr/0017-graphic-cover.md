# 0017 画像なしの表紙・章扉は、テーマの色の図形で飾れる（layout: graphic）

- 日付: 2026-10-09
- 状態: 採用

## 決めたこと

1. `cover` と `section` に `layout: graphic` を足す。写真の代わりに、表紙は右の 880×1080、章扉は右半分（960×1080）を図形で飾る。
   文字の置き方は、右に写真を置くとき（split）と同じ
2. 図柄は `motif` で選ぶ: `circles`（重なる円）・`grid`（点の格子と四角）・`bands`（斜めの帯）・`blocks`（色の面の組み合わせ）。
   省くと資料の題から決める（同じ資料の表紙と章扉はそろい、資料ごとには替わる）
3. 図形はインラインの SVG の基本図形（円・四角・多角形・折れ線）だけで描く。PPTX では図形のままで、あとから色や形を直せる
4. 色はテーマの `primary`・`accent`・`primary-strong`・`surface` と、その透明度だけ。ブランドを替えれば図形の色も替わる
5. 図形は層に分け、画面に入ったら層ごとに少しずつ遅れて出る。クリックの段は増やさない（`talk` の数は変わらない）。handout では動かない
6. 画面の端で切れて見える図形は、切った形の多角形にする（SVG の中の図形も section の外に出ると check が止めるため）。
   切れてよいのは画面の端だけで、文字の側の縁で切れる図形は置かない
7. ロゴの置き場を測るとき、図形の飾り（`svg.art`）は写真と同じく「かかるもの」に数える（右下が飾りなら左下へ）

## 理由

- 画像を使わない資料では、表紙・章扉の変化を付ける置き方がすべて写真の前提で、どの資料も白地に文字だけの表紙になっていた
- 図柄を台本の側で細かく指定させると、台本を書く側の負担が増え、資料の中で揃わない。4つから選ぶか省くだけにした
- 画像に焼かず図形にするのは、文字と同じく PPTX で直せるようにするため（ADR 0001）

## 見送ったこと

- 本文のページへの飾り。中身の読みやすさと、文字の側の検査（コントラスト）を崩さないために、表紙と章扉だけにした
- 締め（closing）への飾り。必要になったら同じ部品で足せる
- 図形のモーフでのつながり（表紙の図形が次のページへ形を変えて残る）。名前の対応と動きの検査が要るので後回し

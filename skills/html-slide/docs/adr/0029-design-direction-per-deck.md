# 0029 型は持ち続け、資料ごとの「見た目の方針」を型に足す

- 日付: 2026-11-18
- 状態: 案（見本を並べて確かめている途中。確かめた結果は末尾の「確かめたこと」に足す）

## 背景

html-slide の質を上げるにあたり、作り方を2つ比べた。

| | テンプレ整備型（今の html-slide） | その場で設計する型 |
|---|---|---|
| 見た目を決めるのは | 型（製品が持つ） | 毎回の作り手（LLM が座標・色・大きさを書く） |
| 質の上限 | 型の語彙まで | 作り手の腕まで |
| 質の下限 | 機械の検査（はみ出し・コントラスト）で保証 | 画像にして目で見る検品しだい |
| 同じ中身で2度作ると | 同じ見た目 | 毎回違う |
| 動き・ノート・1枚ずつの直し | ある | 無い（作り直し） |
| 日本語の字幅 | 字体で実測 | 描き出しの代用字体しだい |

その場で設計する型の資料がよく見える理由を観察すると、座標の自由さよりも、**作り始める前に資料ごとの方針を決めていること**にあった。

- 題材に合わせた配色。1色が画面の 6〜7 割を支配し、差し色は1つ
- 表紙と締めは暗く、中身は明るく、という明暗の組み立て
- モチーフを1つ決めて全ページで繰り返す
- どのページにも視覚要素（図・数字・アイコン）を置く
- 端の色の線・題の下の線・箱の片側の線を使わない
- 全ページを画像にして見て、直す

今の html-slide の見本を描いて見ると、弱いのはちょうどこの部分だった。

1. 中身のページが全部「白地・上の短い帯・左上の見出し」で、明暗の変化が章扉にしか無い
2. 色が主役の1色と灰色で、主役の色が画面を支配する面が無い
3. 箱の頭の短い線・見出しの上の短い帯・主張の左の縦線（どれも端の色の線）
4. 中身を上から詰めるので下が空く（文字は grow で上がるが、縦の置き場は動かない）
5. 箱の題が語の途中で折れる

## 決めたこと（案）

1. **型は持ち続ける。** 座標をその場で書く作り方には替えない
2. **資料ごとの見た目の方針を、型の側の語彙として足す。** 台本を書く側は選ぶだけで、座標は書かない
   - 明暗の組み立て（表紙・章扉・主張・締めを主役の色の面にする）
   - 主役の色が支配する面（箱・帯・数字の地）
   - 端の色の線をやめ、面・余白・アイコンで区切る
   - 中身の縦の置き場（上に詰めず、置ける高さの中で釣り合う所に置く）
3. **評価基準を決め、画像で講評してから型に入れる。** 直しは見本で良かったものだけを入れる

具体の直しは、見本の周回で決める（下の「確かめたこと」）。

## 評価基準

各 1〜5 点。8 は足切り（1つでもあれば、ほかが良くても不合格）。

| # | 基準 | 見る所 |
|--:|---|---|
| 1 | 伝わるか | 見出しだけ順に読んで筋が分かる。1枚に言いたいことが1つ |
| 2 | 情報の整理 | 大事な順に目が動く。まとまりが箱・余白で分かる。同格のものが同格に見える |
| 3 | 余白 | 空きが片側に偏らない。端と塊の間がそろう。詰めすぎ・すかすかが無い |
| 4 | 色 | 主役の色が支配し、差し色は絞る。題材に合う。文字が読める濃さ |
| 5 | 図の使い方 | 構造（順番・比較・割合・関係）を図で見せる。飾りだけの図形が無い |
| 6 | 文字 | 見出し・数字・本文の大きさの差。折り返しの位置。1行の長さ |
| 7 | 資料全体の調子 | 表紙・章扉・締めの明暗。同じ組みの連続が無い。題の位置・図の書式がページ間でそろう |
| 8 | 壊れていない（足切り） | はみ出し・重なり・語や数字と単位の泣き別れ・読めない濃さ |
| 9 | あとから直せる | 文字・図形が PowerPoint の部品で、色と字体をまとめて替えられる |

## 理由

- 製品の使われ方は、無人のワーカーが台本を書き、1枚ずつ直し、版を戻し、ブランドの色を差し替える形。どれも「同じ台本なら同じ見た目」「検査で下限を守る」が前提で、その場で設計する型では成り立たない
- 一方で、質の差の出どころは座標の自由ではなく方針の有無なので、型の語彙に移せる
- 方針を型に入れれば、台本を書く LLM の腕に左右されず、全部の資料が底上げされる

## 却下した案

| 案 | 却下の理由 |
|---|---|
| その場で設計する型に乗り換える | 再現性・検査・動き・1枚ずつの直しを失う。日本語の字幅を実測できない |
| 型を増やし続ける | 弱いのは型の数ではなく、資料全体の方針（明暗・色の支配・区切り方） |
| 台本に座標や色を自由に書ける口を足す | 検査できない形が増え、台本を書く側の負担と出来のばらつきが増える |

# 0029 型は持ち続け、資料ごとの「見た目の方針」を型に足す

- 日付: 2026-11-18
- 状態: 採用

## 背景

html-slide の質を上げるにあたり、作り方を2つ比べた。

| | テンプレ整備型（今の html-slide） | その場で設計する型 |
|---|---|---|
| 見た目を決めるのは | 型（製品が持つ） | 毎回の作り手（LLM が座標・色・大きさを書く） |
| 質の上限 | 型の語彙まで | 作り手の腕まで |
| 質の下限 | 機械の検査（はみ出し・コントラスト）で保証 | 画像にして目で見る検品しだい |
| 同じ中身で2度作ると | 同じ見た目 | 毎回違う |
| 動き・ノート・1枚ずつの直し | ある | 無い（作り直し） |
| 日本語の字幅 | 字体で実測 | 描き出しの代用字体しだい |

その場で設計する型の資料がよく見える理由を観察すると、座標の自由さよりも、**作り始める前に資料ごとの方針を決めていること**にあった。

- 題材に合わせた配色。1色が画面の 6〜7 割を支配し、差し色は1つ
- 表紙と締めは暗く、中身は明るく、という明暗の組み立て
- モチーフを1つ決めて全ページで繰り返す
- どのページにも視覚要素（図・数字・アイコン）を置く
- 端の色の線・題の下の線・箱の片側の線を使わない
- 全ページを画像にして見て、直す

今の html-slide の見本を描いて見ると、弱いのはちょうどこの部分だった。

1. 中身のページが全部「白地・上の短い帯・左上の見出し」で、明暗の変化が章扉にしか無い
2. 色が主役の1色と灰色で、主役の色が画面を支配する面が無い
3. 箱の頭の短い線・見出しの上の短い帯・主張の左の縦線（どれも端の色の線）
4. 中身を上から詰めるので下が空く（文字は grow で上がるが、縦の置き場は動かない）
5. 箱の題が語の途中で折れる

## 決めたこと

1. **型は持ち続ける。** 座標をその場で書く作り方には替えない
2. **資料ごとの見た目の方針を、型の側の語彙として足す。** 台本を書く側は選ぶだけで、座標は書かない
   - 明暗の組み立て（表紙・章扉・主張・締めを主役の色の面にする）
   - 主役の色が支配する面（箱・帯・数字の地）
   - 端の色の線をやめ、面・余白・アイコンで区切る
   - 中身の縦の置き場（上に詰めず、置ける高さの中で釣り合う所に置く）
3. **評価基準を決め、画像で講評してから型に入れる。** 直しは見本で良かったものだけを入れる

具体の直しは、見本の周回で決めた（下の「確かめたこと」と「入れたもの」）。

## 評価基準

各 1〜5 点。8 は足切り（1つでもあれば、ほかが良くても不合格）。

| # | 基準 | 見る所 |
|--:|---|---|
| 1 | 伝わるか | 見出しだけ順に読んで筋が分かる。1枚に言いたいことが1つ |
| 2 | 情報の整理 | 大事な順に目が動く。まとまりが箱・余白で分かる。同格のものが同格に見える |
| 3 | 余白 | 空きが片側に偏らない。端と塊の間がそろう。詰めすぎ・すかすかが無い |
| 4 | 色 | 主役の色が支配し、差し色は絞る。題材に合う。文字が読める濃さ |
| 5 | 図の使い方 | 構造（順番・比較・割合・関係）を図で見せる。飾りだけの図形が無い |
| 6 | 文字 | 見出し・数字・本文の大きさの差。折り返しの位置。1行の長さ |
| 7 | 資料全体の調子 | 表紙・章扉・締めの明暗。同じ組みの連続が無い。題の位置・図の書式がページ間でそろう |
| 8 | 壊れていない（足切り） | はみ出し・重なり・語や数字と単位の泣き別れ・読めない濃さ |
| 9 | あとから直せる | 文字・図形が PowerPoint の部品で、色と字体をまとめて替えられる |

## 理由

- 製品の使われ方は、無人のワーカーが台本を書き、1枚ずつ直し、版を戻し、ブランドの色を差し替える形。どれも「同じ台本なら同じ見た目」「検査で下限を守る」が前提で、その場で設計する型では成り立たない
- 一方で、質の差の出どころは座標の自由ではなく方針の有無なので、型の語彙に移せる
- 方針を型に入れれば、台本を書く LLM の腕に左右されず、全部の資料が底上げされる

## 却下した案

| 案 | 却下の理由 |
|---|---|
| その場で設計する型に乗り換える | 再現性・検査・動き・1枚ずつの直しを失う。日本語の字幅を実測できない |
| 型を増やし続ける | 弱いのは型の数ではなく、資料全体の方針（明暗・色の支配・区切り方） |
| 台本に座標や色を自由に書ける口を足す | 検査できない形が増え、台本を書く側の負担と出来のばらつきが増える |

## 確かめたこと

同じ原稿を3本（14 枚の提案・8 枚の四半期の報告・8 枚の事業の紹介）、その場で設計する作り方と html-slide の両方で作り、全ページを画像にして並べた。作り手は同じモデル。

| | その場で設計する作り方 | html-slide（直す前） |
|---|---|---|
| 見た目 | 上。暗い面・枠なしの淡い面・主役の1枚・置ける高さを使い切る | 下。中身が上に小さく固まり、箱は灰色の枠 |
| 原稿 | 原稿に無い一言・数を足した（表紙の一言、図の埋まり具合の数） | 変えない |
| 手数 | ビルド 3〜5 回。グラフの中身を後から書き換えた資料もあった | 1 回。ただし表のセルが入らず 3 回止まった台本があった |
| 文字 | 題 30pt・本文 12〜20pt（自分の目安の 36pt を割った） | 題 64〜80px・本文 28px 以上 |

5 周して分かったこと。

1. 差の大半は **明暗の幅** と **置ける高さの使い方** だった。色の数ではない
2. テーマの色を1つの濃さに寄せて全部の用途に使うと、明るい主役の色（黄）が茶色に沈む。用途ごとに役を分ければ、指定した色そのものを面に使える
3. ほぼ黒の面は、主役の色の色相を残しすぎると濁る（黄で焦げ茶になった）。彩度はごくわずかにする
4. 強める箱をほぼ黒にすると、差し色の出番が無くなる。強める箱は差し色、ほぼ黒は表の見出し・結論の帯・締め・主張にする
5. 表紙をほぼ黒にすると、明るい主役の色の資料で題材の色らしさが落ちる。表紙と章扉は主役の色の面にする
6. 残る差は「1枚ごとの組みが中身で変わること」。主役を大きく置く組みと構成図の型で一部を埋めた。中身から絵を思いつく部分（割合のマスなど）は、台本を書く側に残る

公開されているスライド生成の道具も 10 個見比べた。完成したテンプレを持つ方式は、テンプレ・文書・検査がずれる・合う版面が無いと追加が続く、という不満が出ていた。言葉で指示する方式は、質が作り手のモデルしだい・必読の文書が長くなって手順を飛ばす、という不満が出ていた。日本語の組版の指針を持つものは無かった。よそのテンプレは写さず（HTML の決まりに通らない・許諾の合わないものがある）、見て決まりを抜き出し、こちらの型として実装する。

## 入れたもの

| 何 | 中身 |
|---|---|
| 色の役 | `primary-fill`・`accent-fill`（テーマの色そのままの面）と `on-…-fill`（その上の文字。白か ink の読める方）。`deep`（ほぼ黒の面）・`on-deep`・`deep-pop`（その上で強める色）。どれも 4.5:1 を検査する |
| look | `surface: flat`（枠なしの淡い面）・`fill: stretch`（並ぶ箱を置ける高さへ伸ばす。中身の 1.6 倍まで）・`title: solid`（表紙・章扉は主役の色の面）・`statement: deep`・`emphasis: deep`・`deep: on`（表の見出し・結論の帯・締め） |
| 既定 | `standard` をこの look にした。前の飾り（箱の枠・上の帯・白い表紙）は `classic` として残す。組み方の直しはどのスタイルにも効くので、`classic` でも前の版と同じ組みには戻らない |
| 組み方 | 表の列の幅と揃えを中身から決める／カードの高さを中身で数える／カタカナの語を途中で折らない／`layout: lead`（主役の1つを左に大きく。cards・summary） |
| 型 | `layers`（構成図。層に箱を並べ、矢印でつなぐ） |

## 改めた決まり

- [ADR 0020](0020-dads-foundations.md) の 5.「箱は外周の枠を持つ」は、`classic` だけの決まりになった。既定は枠なしの淡い面（地との差は 3:1 に届かない）。投影や印刷で境が薄くなることを受け入れ、見た目を優先すると利用者が決めた（2026-11-18）。境をはっきり見せたい資料は `classic` を選ぶ
- [ADR 0005](0005-styles-standard-visual.md) の「standard は look を持たない」は、「classic は look を持たない」に替わる

## 見送ったこと

- 利用者が選ぶ3色目: 色相は主役と差し色の2つで足りた。選ぶ色が増えると、合わない組み合わせが増える
- グラデーションの塗り: 箱には写せず（HTML の決まり）、塗りの上の文字の検査が難しい
- 構成図の「箱の中の箱」・3 層を越える図: 要る資料が出てから
- 大きな数字・年表・グラフの脇の箱で、置ける高さを使い切ること: 次の直しの候補
- 中身から絵を作る型（割合のマス・埋まり具合）: 次の直しの候補

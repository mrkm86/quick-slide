# 画像の枠を埋める

**`prompt` だけの枠は、`deck` が Codex（ChatGPT のサブスク枠の gpt-image-2）で描いて埋める**（2026-10-07・[ADR 0011](../docs/adr/0011-fill-images-with-codex.md)）。
叩き台を「10枚ぐらいでざっと」作ったときに、最初から絵の入った形で返すため。前は「画像を作らず、枠の一覧を出して呼ぶ側が埋める」だった。

- 出どころは3つ: **持ち込み**（台本の `path`・置き場 `images/s{NN}-{枠}.png` に置いた絵）／**生成**（`prompt` だけ）／図解（型）。描くのは生成だけ
- 生成の絵はキャッシュの区画（台本のフォルダごと）の `gen-<鍵>.png`（横に何から描いたかの `.json`・[ADR 0014](../docs/adr/0014-cache.md)）。前の置き場 `images/gen-<鍵>.png` にあれば区画へ写して使う。鍵は描く指示（prompt・文字を重ねる側・画風・色・キャラ・形）から作り、
  ページ番号を入れない。ページを足しても並べ替えても描き直さない。prompt・画風・キャラの絵を変えた枠だけ描き直す
- 認証は1回の実行で1度だけ確かめ、並列で描く（既定8本）。Codex の呼び方は image-slide の `codex_run.py` の写し（`--image-look` の言い回しと一緒にテストで見比べる）
- `fill` は描くだけ（PPTX は作らない）。`deck --no-fill` は描かずに仮の枠。`revise` は生成の絵1枚を直して deck を組み直す
- 下の「描かせるときの決まり」と画風・キャラは、`images --json` の `gen_text`（Codex に渡す描く指示そのもの）に入っている

以下は、呼ぶ側が自分で描いて置く（別の画像生成・手持ちの写真）ときの約束。置き場に置けば、それが使われる（Codex は描かない）。

## 流れ

1. 台本の画像の枠に `prompt`（何を描くか）を書く。パスは書かなくてよい
   ```json
   "image": {"prompt": "明るい会議室。左は空いた壁", "focus": "right", "alt": "会議室"}
   ```
2. 枠の一覧を出す（無い枠だけ・JSON にも書く）
   ```bash
   python3 <このスキルのフォルダ>/scripts/html_slide.py images --script deck.json --missing --json slots.json
   ```
   1件ごとに `path`（置き場）・`size`（目安の画素数）・`aspect`（枠の縦横比）・`crop`（切り抜き方）・`prompt_full`（下の決まりを足した描く指示）が入る
3. 画像を作って `path` に置く（下の「自分で描いて埋める」）
4. `html_slide.py deck --script deck.json` で PPTX にする。画像がまだ揃っていない下書きは `--placeholder`（仮の枠を描く。検品では落ちる）

置き場の既定は `<台本のフォルダ>/images/s{NN}-{枠の名前}.png`（`.jpg`・`.jpeg`・`.webp` も探す）。

## 描かせるときの決まり（`prompt_full` に自動で足される）

- **文字・ロゴ・透かしを描かせない。** 文字は型が上に重ねる（あとで直せるように・日本語の誤字を出さないように）
- 文字を重ねる型では、**文字を置く側を空けさせる**（例: 「左45%は物を置かずに空ける」）
- 大事なものは `focus` の側に置かせる（枠に合わせて切り抜くため）

## 縦横比と切り抜き

**枠の縦横比と、届く画像の縦横比は一致しない前提**にする。型は `object-fit: cover` で切り抜いて収め、
切り抜く位置は `focus`（`center` / `left` / `right` / `top` / `bottom` / `"40% 30%"`）で決める。

⚠️ 実測（2026-10-03）: Codex 経由の gpt-image-2 は**画素数を指定できない**。
1536x1024 を頼んでも **1774×887（2:1）** で返った。16:9 の全面に入れると左右が少し切れ、
縦長や正方形の枠に入れると大きく切れる。`size` は目安として扱う。

## 自分で描いて埋める（手で埋めたいときだけ。普段は deck が描く）

```bash
python3 <このスキルのフォルダ>/scripts/html_slide.py images --script deck.json --missing --json /tmp/slots.json
```

- `origin` が `generated` の枠だけを描く（持ち込みの無い絵は描かない。`path` を直す）
- 描く指示は `gen_text`（画風・キャラの言葉まで入っている）、大きさの目安は `size`。描けた絵を `path` に置く
- 画像生成の道具は問わない。並行して何本走らせてもよい
- 描けたら、確認用の PNG（`slides/`）で、文字が空けた側に乗っているかを見る

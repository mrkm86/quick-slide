Quick Slide の形式は3つ。左のカードの中身を、右の表へ入れていきます。

プレゼンは編集できる PPTX になります。カードの言葉が、そのまま表のマスへ飛ぶところを見てください。

ピッチの仕上がりは、画像生成で1枚ずつ描いた絵です。

モーションは、クリックで進む HTML 1枚。記事や話題を、順を追って説明したいときに向いています。

作り方は5つの段に分かれます。頼む、台本を書く、組み立てる、見て直す、書き出す、の順です。

線でつなぐと、順番がひと目で追えます。頼むのは会話でも、ホームの入力欄からでもかまいません。

直すときは、ページを選んで指示を書くだけ。大事なところは、こうして手書きの丸で囲めます。

このスライドは見本なので、消してもかまいません。設定の「見本」から、いつでも戻せます。

自分のスライドを作るときは、会話で「この記事をモーションスライドにして」と頼むか、ホームの入力欄に書いてモーションを選んでください。

仕上がりは、外から何も読み込まない HTML 1枚。Chrome か Edge で開き、書き出しは HTML とページの画像です。形式は作るときに選ぶもので、あとからは変えられません。

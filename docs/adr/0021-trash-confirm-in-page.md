# 0021 ゴミ箱への移動はページ内で確認する

## 採用

資料を1件またはまとめてゴミ箱へ移す前に、HTML の確認ダイアログを表示する。
実行ボタンを押したときだけ削除 API を呼ぶ。取り消し・Escape・背景クリックでは移動しない。
初期フォーカスは取り消しに置き、Tab をダイアログ内に留める。

内蔵ブラウザでは `window.confirm` が表示されず、削除操作が進まない場合があるため。
完全削除は既存のページ内の確認を維持する。

## 却下

確認を省略する: 誤操作で資料が移動する。
ネイティブ確認が拒否されたらそのまま削除する: 取り消しと、確認機能が使えない状態を区別できない。

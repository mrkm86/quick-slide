# 0036 ページの文字を、人が直接書き換える（直す板の「自分で直す」）

- 日付: 2026-11-19
- 状態: 採用
- 関係: `docs/adr/0008-edit-kinds.md`（何を直しますか）・`docs/adr/0014-imported-text-edits.md`（取り込んだページの文字）・
  `docs/adr/0033-writer-uses-free-pages.md`（自由なページ）

## 決めたこと

- 直す板（1 ページ）に、直し方の切り替えを置く: **「自分で直す」と「AI に頼む」**。「AI に頼む」は今までの欄で、はじめはこちら
- 「自分で直す」は、そのページの文字を欄に並べ、人が書き換えて保存する。**台本係は通らない**。位置・色・書式・組み・動きは変えない
- 欄にするのは、見える文字だけ（`src/quick_slide/pagetext.py`）
  - 取り込んだページ（PPTX から）: HTML の文字（0014 と同じ番号。箇条書きの印だけの文字は出さない）
  - 自由なページ: 見出しなどのキーの文字と、`body` の HTML の文字
  - 型のページ: 台本のキーのうち、**見える文字の名前のキーだけ**（見出し・本文・項目など。名前で許可する）。描き方の指定
    （図柄・札の描き方・進み具合・並べ方）・話す台本・画像の指示・アイコンの名前・知らないキーは出さない
- 口は `GET /api/decks/<id>/pages/<slide_id>/texts`（欄）と `POST …/texts`（`{changes: [{ref, from, text}]}`）。
  `from` は画面が開いたときの文字で、いまの台本と違えば当てない（ほかの直しが先に当たって欄がずれたとき、違う文字を書き換えない）
- 画面は「受け付けた」と「保存できた」を分ける。送ってから仕事が終わるまで欄は書けず、書きかけは消さない。終わったら台本から
  読み直し、当たらなかったときは書きかけと理由を出す
- 保存は直しの仕事 1 つ（`op: retext`）。当てた台本をエンジンの検査に通し、通らなければ当てずに理由を返す。通ればそのページを描き直す。
  版は 1 つ進み、前の版に戻せる
- 欄を足す・消す・空にすることはできない。はみ出しは止めず、描き直したあとのページの知らせに出る
- プレゼン（html-slide）だけ。ピッチ（文字も絵として描く）・モーション・全ページを 1 枚に描くスタイル・デザインテンプレートの資料は、
  理由を出して「AI に頼む」へ案内する

## 理由

- 「14 台を 16 台に」のような、答えの決まっている直しまで文章で頼むのは回りくどい。台本係を呼ぶと 20 秒ほどかかり、
  頼んでいない所まで変わることがある
- スライドの上で直接書き換える画面は、位置・書式・動きを壊さずに作るのが難しい。文字の欄を並べる形なら、取り込んだページの
  文字の差し替え（0014）と台本のキーの書き換えだけで済む
- 「何を直しますか？」の 4 つ（文字・図解・挿絵・画像）は、自分で決めて直したいものと、頼んで作ってもらうものが混ざっていた。
  先に直し方を分ける

## 却下した案

| 案 | 却下の理由 |
|---|---|
| スライドの絵の上で文字を直接書き換える | 絵は描いた結果で、文字の箱の位置・折り返し・動きを画面で再現することになる |
| 画面で台本（JSON）をそのまま書き換えさせる | 型の決まり・HTML を知らないと壊す。使う人の言葉でない |
| 保存を、仕事を作らずその場で当てる（非表示・並べ替えと同じ） | 文字が変わるとページを描き直す。検査も要るので、仕事にして進みを見せる |
| はみ出したら保存を断る | 取り込んだページは字体の違いでもともとはみ出しの警告が出ることがある。人が決めた文字は当て、知らせる |

## 残したこと

- 行（箇条書きの項目）を足す・消す
- 数（グラフの値など、文字でないもの）の書き換え
- 手持ちの画像を入れる・差し替えるのを「自分で直す」へ移す。「AI に頼む」の札の整理
- 会話の入口から、文字を指定して書き換える

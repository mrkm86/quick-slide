# 0032 設定を替えて組み直す操作をなくす

- 日付: 2026-10-19
- 状態: 採用
- 関係: Issue #38・ADR 0001・ADR 0009・ADR 0030

## 決めたこと

資料のメニューの「設定を替えて組み直す」と選択の窓、専用の GET `/api/decks/<id>/look`・POST `/api/decks/<id>/rebuild`、
`capabilities.rebuild`、新しい直しとしての `rebuild` の受付と実行をなくす。
別のブランド・見せ方・テンプレートで作りたいときは、同じ原稿から新しい資料として作る。元の資料と見比べられる。

## 理由

完成した資料を別のブランドに替えて描き直す需要は確認できていない。
テンプレートの資料は作ったときのブランドとテンプレートで固定する約束とも合わない。
必要になったら、実際の使われ方に合わせて設計し直す。

## 残すもの

過去の `rebuild` を含む仕事・描いた回・ページ版の記録は変更しない。読み出し時に新規操作の列挙で検査しないので、
そのまま履歴を表示し、見せる回のファイルを書き出せる。データ移行は不要。
直し・差し込み・再開・ページ版の復元、描かない直しの後や書き出しのための `render` は残す。
取り込んだページを画像や図解が主役の型へ作り直す操作（ADR 0015）も残す。

## 却下した案

| 案 | 却下の理由 |
|---|---|
| メニューだけ隠して API と実行処理を残す | 需要の分からない機能の保守が続く |
| テンプレートの資料だけ断る | 通常の資料にも、新しい資料として作る代替手段がある |
| 過去の記録からも組み直しを消す | 履歴やページ版の参照を壊す必要はない |

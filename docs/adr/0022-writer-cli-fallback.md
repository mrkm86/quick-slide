# 0022 台本係の自動選択は、導入済みの CLI を使う

## 採用

`writer: auto` は会話元の CLI を優先し、それが見つからなければ導入済みのもう一方を使う。
両方ない場合は導入を案内する。`writer: claude` / `codex` の明示的な指定は保持し、指定先がなければ失敗する。
CLI があるが認証・実行に失敗した場合には、別の CLI で再実行しない。

デスクトップアプリと同じ名前の CLI を導入していなくても、どちらかの台本用 CLI があれば使えるため。
画像生成は引き続き Codex が必要で、この変更は台本係の選択だけに適用する。

## 却下

会話元の CLI がなければ常に止める: デスクトップから使うために不要な追加導入を要求する。
明示的に固定された台本係も切り替える: 利用者の指定に反する。
認証エラーも自動で切り替える: 実行失敗の原因と利用するアカウントが分かりにくくなる。

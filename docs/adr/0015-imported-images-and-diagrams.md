# 0015 取り込んだページ（PPTX から）の画像と図解（空いた所に足す・差し替える・主役にして組み直す）

- 日付: 2026-10-14
- 状態: 採用
- 関係: `docs/adr/0013-overlay-illustrations.md`・`docs/adr/0014-imported-text-edits.md`・`docs/adr/0011-import-pptx.md`

## 決めたこと

取り込んだページの修正の欄に「画像」と「図解」を出す。選んだら、選び方の札で直し方を決める（1 ページずつ）。

| 札 | 選び方 | やること | 元の見た目 |
|---|---|---|---|
| 画像 | 空いた所に足す | 渡した画像か生成した画像を、空いた所に重ねる（写真は枠いっぱいに切り抜く） | 保つ |
| 画像 | 差し替える | ページの中の画像 1 つを、同じ枠のまま中身だけ替える。**ページに画像があるときだけ出す** | 保つ |
| 画像 | 主役にして組み直す | 画像を主役にした型のページ（photo など）に組み直す | 型のものに変わる |
| 図解 | 空いた所に足す | 箱・矢印・短いラベルの図を SVG で描いて重ねる（PPTX では 1 枚の絵） | 保つ |
| 図解 | 主役にして組み直す | 図解の型のページ（flow・hub・matrix など）に組み直す（PowerPoint で直せる部品） | 型のものに変わる |

- **画像の出どころ**: 「＋」で画像を渡していればその画像（渡した画像の札は「入れる」）。渡していなければ生成する
  （Codex が要る。生成できない機械では、足す・差し替えるに画像を渡すよう言う。組み直すは挿絵の枠にする）
- **生成**: エンジンの `fill` に、画像の枠 1 つだけの仮の台本（photo。縦長の箱なら右半分の縦長の枠）を渡して Codex に描かせ、
  `images --json` で置き場を聞いて、台本のフォルダの `overlays/` に写す（テーマと画風はその回のもの）。仮の台本は残さない
- **足す**: 挿絵（ADR 0013）と同じ道。台本係が空いた場所・大きさを決め（渡した画像なら縦横比を合わせ、生成なら何を描くかも）、
  サーバが確かめて、ページの `illustrations` に足す（画像は `{"image": {"path"}, "fit": "cover"}`、図解は SVG）
- **前に重ねたものにも重ねない**: 台本係に渡す箱に、ページの `illustrations`（前に足した挿絵・図解・画像）を「重ねた絵」として足し、
  文字の箱と同じく重なりを面積の 1 割までにする（生成した画像が前の挿絵を隠したことがあった。2026-10-14）
- **差し替える**: ページの HTML の `<img>`（背景を除く）の n 番目の `src` だけを替える（`importing.replace_image`。位置・大きさ・
  切り抜き方は元のまま）。画像が 1 つで、渡した画像があり、指示の文が無ければ台本係を呼ばない
  前に重ねたもの（`illustrations`）も替えられる（位置と大きさはそのまま、中身だけ）。候補は**見えているものだけ**で、
  あとから重ねたものの下に半分より多く隠れたものは出さない。替えた枠の下に大半が隠れていた重ねたものは取り除く
  （下に隠れた図を替えて、上の画像の周りからはみ出したことがあった。2026-10-14）
- **組み直す**: 台本係に、元のページの言葉と「台本の決まり」を渡し、同じ id の型のページ 1 枚を書かせる。検査は今の道
  （エンジンの check）。**送る前に、見た目が変わることを確かめる一言を出す**（画面の `SS.confirm`）
- 複製では、台本のフォルダの `overlays/`（生成した画像。作り直せない）と `illustrations/` も写す

## 理由

- 「空いた所に足す」と「その画像（図解）を主役にして組み直す」は、使う人にとって別の頼みごと（2026-10-14 に整理）。
  元の見た目を保ちたいか、画像（図解）を見せることがページの目的になるかで選ぶ
- 差し替えは、PowerPoint で写真を入れ替えるのと同じ感覚で、位置と大きさを保てる
- 生成をエンジンの `fill` に任せれば、Codex の呼び方・キャッシュ・画風・テーマを、エンジンの決まりのまま使える

## 却下した案

| 案 | 却下の理由 |
|---|---|
| フリー素材を検索して入れる | ADR 0008 で見送った（渡された画像だけを使う） |
| 生成をサーバが Codex に直接頼む | Codex の呼び方・画風・キャッシュの正本がエンジンと 2 か所になる |
| 組み直すのを確かめずに送る | 見た目が大きく変わる。版を戻せば戻るが、気づきにくい |

## 残したこと

- 重ねた画像・図解だけを消す・動かす操作（いまは版を戻す）
- 図解を足すときの図の中の文字を、あとで直す道（PPTX では 1 枚の絵）

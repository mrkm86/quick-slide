# 0033 台本係は、中身のページをまず自由なページで組む

- 日付: 2026-11-19
- 状態: 採用
- 関係: html-slide の ADR 0030（自由なページの型 `free`）の段階 2・ADR 0008（直しの種類）・ADR 0015（取り込んだページの組み直し）

## 決めたこと

サーバが台本係に渡す「守ること」と、直しの方針の文を、html-slide の台本の決まり（`deck-format.md` の「書く前に」の 9）に合わせる。

- **プレゼン（html-slide）**: 構造・手順・比較・数字のページは、まず自由なページ（`type: free`）で中身に合う形に組む。
  形の決まっているもの（表・折れ線・軸の要る棒グラフ・構成図・中心と周りの図・2×2・年表）は型を使う
  - 作るとき（`DIAGRAM_RULE`）・構成が決まっているとき（`_OUTLINE_RULES`）・直しの「図解」（`edit_kinds` の方針の文）・
    取り込んだページを図解に組み直すとき（`build_rebuild_prompt`）の 4 か所
- **ピッチ（image-slide）**: 自由なページは使わない。各ページを絵で描くので、`body` の HTML の組みは使われず、
  描き方の注文（`_visual`）も型のページのほうが渡しやすい。台本の決まりは 2 つのモードで同じ文書を読むので、
  「まず free」を読み替える 1 行（`PITCH_NO_FREE`）を、作るときと直すときの両方に足す
- **自由なページの直し**: 指示が組み替え・図解を求めていなければ、`body` の組み（要素・class・style・`data-…`）を変えず、
  文字だけを直す（`FREE_EDIT_RULE`）。数字を直すときは、その数を表す属性（マスの `data-on`、棒の `data-value` など）も同じ数に直す
  （図と文字を食い違わせない）。見出し・出典・結論は台本のキーで直す
  - **直しの種類が「文字」のときは、サーバが確かめる**: 直す前と後の `body` の骨組み（要素・class・style・動きの属性の並び。
    文字と、中身の数を表す属性は除く。マスの列の数は並べ方なので含める。class の語の順・style の空白と順は違いにしない）を見比べ、
    変わっていれば（別の型に替えたのも含む）理由つきで書き直させる（`worker/edit.py` の `free_shape_problems`。
    最後の回は止めない）。図解・挿絵・画像の直しと、種類を選ばない自由な指示は、組み替えてよいので見ない
  - 台本の検査は今までどおりエンジンが行い、決まりに合わない `body`・箱からはみ出す中身は、理由つきで台本係に書き直させる
- **画面の「このページの記録」**: 自由なページの `body` は、見える文字と、マス・棒の数だけを出す（HTML を出さない）

## 理由

型 `free` を足したあとも、サーバの指示は「図解の型（flow・steps・…）で見せる」のままで、台本の決まりの「まず free」と食い違っていた。
画面から作る資料に、自由なページが出にくい。

直した指示で、架空のお題 2 本の台本を書かせて確かめた（書き手は 1 回で書き、直しなし）。8 枚のうち自由なページは 4 枚と 2 枚で、
どちらも検査を 1 回で通った。表・折れ線・棒グラフ・中心と周りの図には型が選ばれた。

## 見送ること

- **自由なページの文字だけを、番号で差し替える道**（取り込んだページの文字の直しと同じ形）。いまは台本係がページを書き直し、
  サーバが骨組みを見比べる。書き直しの回数が目立つようなら入れる
- **数字の直しで、文字と属性の数が合っているかの検査**。指示には書いたが、機械では見ていない（文字のどの数が、どの属性に当たるかを
  決められない）
- **自由なページの中の絵の枠**（挿絵・生成の画像）。html-slide の ADR 0030 の段階 3。それまで、直しの「挿絵」「画像」は、
  画像を置ける型へ替える今の方針のまま
- **ピッチで自由なページを使う**。絵で描くエンジンが組みを読めるようになってから

## 却下した案

| 案 | 却下の理由 |
|---|---|
| サーバの指示から形の話を消し、台本の決まりだけに任せる | 「半分以上を図として見せる」という目安はサーバ側の方針で、台本の決まりには無い |
| ピッチ用に、台本の決まりから `free` の節を抜いて渡す | 文書を機械で切り分ける処理が要る。1 行の読み替えで足りる |

# 0011 既存の PPTX を取り込む（`POST /api/imports`・CLI `--import`・ホームの「PPTX を取り込む」）

- 日付: 2026-10-13
- 状態: 採用（見る・発表する・書き出すまで。取り込んだページを直す道は次の段）
- 関係: `docs/IMPORT-PLAN.md`（計画と決めたこと）・`skills/html-slide/docs/adr/0025-import-pptx.md`（エンジンの写し方）

## 決めたこと

手元の PPTX を、Quick Slide のプレゼン（html-slide）のデッキにする。画像・色・配置はそのまま写し、アニメーションは開始の効果だけ写す。
**写すのはエンジン（`html_slide.py import`）、デッキにするのはサーバ。** 違いは `src/quick_slide/importing.py` に閉じ込める。

1. **口は `POST /api/imports`**（本文は PPTX のバイト列そのまま。名前は `X-Quick-Slide-Filename` か問い合わせの `name`）。
   画面（ホームの作成の欄）と会話の CLI（`quick_slide_start.py --import <file>`）は同じ口を通す。エンジン単体の `import` は
   スキルだけで使うときの口
   - 本文は、宛先・オリジン・セッションを確かめてから、ディスク（`runtime/uploads/`）へ流して受ける。上限は 512 MB
     （ふつうの口の 16 MiB とは別）。断った本文の一時ファイルは答えたあとで消す
   - 形の確かめは名前（.pptx など）と中身の頭（zip）だけ。中身はエンジンが外から来たファイルとして読む（zip の大きさ・名前・XML の実体参照）
2. **台帳**: デッキはプレゼン。取り込み（intakes）の出所は `file`・原稿は空・payload の `import` に名前・大きさ・sha256。
   描いた回の引数に `imported: true`。台本の版の書き手に `import` を足した（移行 0009）
3. **仕事**: 台本係の代わりに、エンジンの `import` で台本を起こす（`worker/pipeline.import_script`）。ページの id は `p-001` …、
   画像は台本のフォルダからの相対 `imported/media/…`（`scripts/imported/` に置く。複製でも写す）。検査は描く段のエンジンがする。
   進みの帯は「PPTX を取り込んでいます」
4. **見た目**: ブランドのロゴ・フッタ・ページ番号は足さない（元の PPTX にもう入っている）。透かしはブランドのまま。
   テーマは PPTX のテーマ（あとで型のページを足すとき、元のページと色をそろえる。エンジンのテーマにできたときだけ）
5. **元の PPTX** は `decks/<デッキ>/source/source.pptx` に残す。画面にも書き出しにも出さない（書き出しは描き直した PPTX・PDF だけ）
6. **画面**: ホームの作成の欄で、形式が取り込める（語彙の `deck_kinds[].importable`。いまはプレゼンだけ）ときだけ
   「PPTX を取り込む」ボタンを出し、ドロップも受ける。押すとファイルを選び、送ったらデッキの画面へ移る
7. **元の非表示のスライド**は非表示のページのまま入れる（戻せば描く）
8. **まだしないこと**: 取り込んだページを直す（台本係は型のページしか書かない）。直しの口は 409 `imported_page` と理由を返す。
   （2026-10-14: 挿絵を重ねる直しと、見た目を保って文字を直す直しは受ける。`docs/adr/0013-overlay-illustrations.md`・
   `docs/adr/0014-imported-text-edits.md`）
   ページを足す・並べ替え・非表示・複製はできる

## 理由

- 写し方（図形・文字・画像・アニメーション）はエンジンの決まりの話で、サーバが持つと 2 か所で直すことになる
- 大きなデッキ（写真の多い 100 枚超で 200 MB）を 16 MiB の上限の口でメモリに読むと止まる。認証の前に本文を読むと、
  知らない相手にディスクを埋められる
- 元の PPTX にもうロゴ・フッタ・ページ番号があるので、ブランドのものを足すと二重になる

## 見送ったこと

- **multipart/form-data で受ける**: 画面も CLI も 1 ファイルしか送らない。いまの画像・ブランドの ZIP の口と同じ「本文がそのファイル」にそろえた
- **取り込み専用の仕事の種類を足す**: 1 冊を作る仕事（make）の書く段を差し替えるだけで済む。止まったときの続き（描く段から）もそのまま使える
- **元の PPTX をそのまま書き出す**: 使う人と決めて、描き直した PPTX だけにした（2026-10-13）

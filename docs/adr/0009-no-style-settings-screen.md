# 0009 スライドスタイルの設定画面をやめる（見せ方はアプリが決め、組み直しで 2 つから選び直す）

- 日付: 2026-10-13
- 状態: 採用
- 関係: `docs/adr/0008-edit-kinds.md`・`src/quick_slide/render/look.py`

## 決めたこと

- 設定の「スライドスタイル」（`/settings/styles`）の画面をなくす。設定のトップからも外す。前の URL は設定のトップを開く
- 見せ方（エンジンの standard・visual）は利用者に設定させない。作るときは、会話からなら会話側が言葉から選び
  （`--style`）、画面からならモードの既定（プレゼンは standard・ピッチは visual）で描く
- 「設定を替えて組み直す」で選べる見せ方は、付属の 2 つだけにする: 「説明・報告（文字と図で説明する）」と
  「ビジュアル（絵で印象を残す）」。1 枚にまとめる（infographic）は最初の回で決まり替えられないので並べない。
  モーションは見せ方を持たないので、欄ごと出さない
- 直しで何をしたいかは、修正の欄の「何を直しますか？」で選ぶ（ADR 0008）

## 理由

- 画面がエンジンの選択肢（「プレゼンの見せ方」「ピッチの見せ方」）をそのまま見せていて、モーションには効かないなど、
  どこに効くのかが分かりにくかった
- 項目のおよそ半分（文字の感じ・密度・絵の量・描き味の補足）は保存して検査するだけで、どこにも渡っていなかった
- 付属は 3 つで、そのうち 1 つ（インフォグラフィック）の中身は見せ方ではなく「1 枚にまとめる」という構成の指定だった
- 見せ方を選ぶ理由は、たいてい「もっと絵で」「もっと説明的に」で、それは直しと組み直しで言える。設定に保存して
  使い回すほどの需要は、まだ見えていない

## 却下した案

| 案 | 却下の理由 |
|---|---|
| いまの画面を残し、効いていない項目だけ消す | エンジンの選択肢を見せる分かりにくさが残る |
| 作風（手書き風・黒板風など）の一覧を用意して選ばせる | エンジンごとに表現できる幅が違い、ブランドの色ともぶつかる。必要が見えてから決める |
| 保存したスタイルの仕組み（API・DB）も一緒に消す | 会話の入口（`--style-id`）と描く回の控えが使っている。描いたデッキの再現にも要る。画面だけを先にやめる |

## 残したこと

- 保存したスタイルの API（`/api/settings/styles`）と DB はそのまま。前に作ったスタイルを指しているデッキは、
  そのスタイルで描き続ける（組み直しの欄には「いまのまま」として出る）
- 「いつもの自分の作風」を言葉の束として保存して使い回す仕組みは、直しの指示が溜まってから考える

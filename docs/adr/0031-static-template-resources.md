# 0031: テンプレートの素材はスタティックな画像・テキストだけにする

状態: 採用（2026-10-18、#22）。実装は別途。

## 決定

Quick Slide は原稿を資料に仕上げる。調査・事実確認・スキルの実行は投入前の会話で行う（ADR 0029）。
テンプレートのリソースはスタティックな画像・テキストだけを限定読取する。
説明書き・登録テキストにある手順・コマンド・スキル呼び出しは実行されない資料であり、実行・確認済みと扱わない。
構成・追加指示にも、調べものやプログラムを実行させる効力はない。

`SKILL.md`・`quick-slide-read.json` があるフォルダも止めず、通常フォルダとして読む。
説明書きは `SKILL.md` → `README.md` → `README.txt` の最初の1つ。宣言ファイルを実行契約として解釈しない。
画像を見て目録を自動で作る機構は持たない。ファイル名・README の目次・カードの使い方・SKILL.md の書き方で選ばれやすくする方法をヘルプで伝える。

テキストのリソースは原文を準備係と台本係に渡す。パスは渡さない。
直し・差し込みも同じ準備世代の控えを使う。要約だけで代用しない。
限定読取のルート・形式・入力予算・読取前後の同一性・ハッシュの検査は維持する。

## 理由

資料制作と、調査・実行・確認の担当を明確にする。
利用者が登録した素材の文章を読むことと、その文章に書かれた操作を実行することを混同しない。

## 採らなかった案

- 6b の `image-catalog/1` 契約: 宣言・固定操作・子プロセス・指紋・実行許可・最小環境を実装しない。登録を実行許可とみなす旧案は置き換える。
- 画像を見て目録を自動作成する: 素材の整理は利用者のファイル名・目次・説明に基づく。機械的なファイル名・形式・寸法の一覧は維持する。
- スキルの印があれば停止する: 実行せず資料として読めるフォルダまで使えなくなる。
- 台本係へ準備係の要約だけを渡す: 元の用語・条件・数値が落ちる。

この決定は、準備係・台本係・描画エンジンの既存サブスク CLI を廃止する意味ではない。
旧 request 互換経路の下調べ係も変更しない。全経路で調査を廃止したとは説明しない。
詳細は [変更設計](../design-template-static-resources.md) §4〜§7。

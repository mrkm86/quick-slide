# 0013 取り込んだページ（PPTX から）に挿絵を重ねる

- 日付: 2026-10-14
- 状態: 採用
- 関係: `docs/adr/0011-import-pptx.md`・`docs/adr/0011-svg-illustrations.md`・`docs/adr/0008-edit-kinds.md`

## 背景

取り込んだページは型 `html`（PPTX の図形・文字・画像を絶対配置で並べた HTML）で、台本係は型のページしか書かないため、
直せなかった。まずは「このスライドに絵を足したい」に応える。元の見た目を保つことを優先する。

## 決めたこと

- 取り込んだページで受ける直しは、**「挿絵」を 1 ページずつ**だけ。修正の欄にはその札だけを出し、はじめから選んでおく
  （デッキの答えの `imported_edit_kinds`）。ほかの直しは、これまでどおり理由を返す（409 `imported_page`）
- 台本係には、ページの HTML から拾った箱（位置・大きさ・文字か画像か図形か・中の文字。`illustrations.page_boxes`）を渡す。
  台本係は、空いている場所と大きさ（1920×1080 の座標）と挿絵の SVG を返す。置けなければ `skip` に理由を書く（失敗にして理由を出す）
- サーバが確かめる: 箱がページに収まる・幅と高さが 160 以上・**文字の箱との重なりは挿絵の面積の 1 割まで**。外れたら `NG:` で書き直させる
- 台本の版は、ページの `illustrations`（`{"image": {"svg": …}, "x", "y", "w", "h"}` の並び）に SVG のまま持つ。元の `html` は変えない
- 描く前に、サーバが挿絵を PNG にし（ADR 0011 の挿絵のスキル）、ページの HTML の最後に `<img>` として重ねて `illustrations` を消す
  （`illustrations.apply_overlays`）。エンジンは変えない
- 同じページにもう一度頼めば、挿絵はもう 1 つ足される（前の挿絵は残る）。消したいときは版を前に切り替える

## 理由

- 元の文字・図形・画像・アニメーションに触らないので、取り込んだ見た目が崩れない
- 台本係に HTML そのものを書き換えさせると、位置や書式を壊しうる。箱の一覧を渡して「どこに置くか」だけを決めさせる方が確かめやすい
- 台本の版に SVG と位置を持てば、版の切り替え・複製・並列の直し（ADR 0012）の当て直しがそのまま使える

## 却下した案

| 案 | 却下の理由 |
|---|---|
| 型のページとして作り直して挿絵を置く | 見た目が元の PPTX から型のものに変わる |
| 挿絵のページを足す（いまもできる） | 「このスライドに絵を足したい」に合わない。枚数が増える |
| 台本係にページの HTML を直接書き換えさせる | 位置・書式・アニメーションを壊しうる。確かめにくい |

## 残したこと

- 取り込んだページの文字を、見た目を保ったまま直す道（文字の部分だけを番号で差し替える）
- 重ねた挿絵だけを消す・動かす操作（いまは版を戻す）
- 文字の箱が文字より大きいページでは、空いて見える所でも「文字の箱」として避ける（置ける所が狭くなることがある）

# 0003 ブランドの見本は、プレゼンのエンジンが塗る色で描く

- 日付: 2026-10-12
- 状態: 採用
- 関係: `skills/html-slide/docs/adr/0020-dads-foundations.md`・`docs/DADS-PLAN.md`・`docs/P4-NOTES.md`

## 決めたこと

設定のブランドの編集画面のプレビュー（はじめは「配色シミュレータ」と呼んでいた）は、**プレゼン（html-slide）が実際に塗る色の役**で見本を描く。

- 色の役の作り方（DADS のキーカラーの作り方）を `skills/html-slide/scripts/deck_palette.py` に切り出した。
  `deck.py` の `palette()` はこれを土台にし、写真の上の幕に載せる色だけを足す。出す色と CSS 変数の並びは前と同じ
- サーバは `src/quick_slide/slide_palette.py` でそのファイル（と `skills/dads/scripts/keycolors.py`）を読んで呼ぶ。写しは持たない。
  ブランドからテーマへは描く回と同じ `palette.engine_theme` を通す。import の仕組みは通さず読む（エンジンの中に `__pycache__` を残さない・
  `sys.modules` に `keycolors` を残さない）
- `POST /api/settings/brands/preview` の答えに `slide` を足した: `roles`（エンジンが塗る色の役）・`adjusted`（ブランドの色を
  4.5:1 に届かせるため明度を動かした役）・`problems`（エンジンが描かずに止まる組み合わせ）・`error`
- 見本は雛形（`templates/deck.html`）の縮図: 表紙・章扉・箇条書き・棒グラフ・お知らせの枠の 5 枚。字・余白・角は雛形の数字に
  `--u`（見本の幅 ÷ 1920）を掛けるだけ。フッタとページ番号は中身のページだけ（表紙・章扉には入れない。エンジンの決まり）
- 見本の下に「スライドで使う色」を並べ、ブランドの色を濃くしたときはその理由（地との差と、使う色）を書く

### 編集画面の並び

- 見出しの段: パンくず（設定 › ブランド › 名前）→ 名前の欄（H1）。帯（名前・状態・保存）は上部バーの下に貼り付く。保存は右上。⌘S / Ctrl+S でも保存する
- PC: 左に設定の欄（色 → ロゴ → フッター → ウォーターマーク → 詳細設定 → 削除）、右に「プレビュー」（貼り付く）。プレビューには色だけでなく、ロゴ・フッタ・ページ番号・透かしも入るので、
  「配色シミュレータ」ではなく「プレビュー」と呼ぶ
- 狭い画面（900px 未満）: 本文にプレビューを置かず、帯の「👁 プレビュー」から全画面の板（`<dialog>`）で開く。見本（カルーセル）は 1 つだけ持ち、板へ移して閉じたら戻す。
  帯の状態の文は短い言い方（「未保存」など）にする。320px 未満はプレビューを目のアイコンだけにする
- アイコンは目（eye）。三角（▶）はこのアプリでは「動きつきで再生」「発表」に使っているので使わない
- 色: 基本色・強調色を小さく（入力 S・高さ 40）横に並べ、その下に「他の要素の色」（はじめは畳む）。中は 3 つ:
  - **変えられる色**（背景＝`base`・カード・表の背景＝`surface`・本文＝`ink`・補足＝`muted`。「面の色」は伝わらないので画面ではこう呼ぶ）。色見本そのものが色を選ぶ部品で、変えた行には
    「変更済み」の札と左の太線、その行だけを自動に戻すボタン。上に「すべて自動に戻す」。読めない組み合わせはエンジンの検査
    （`contrast_problems`）で拾い、保存させない。カード・表の背景は、本文が読みにくくなるときはエンジンに渡さない（従来の決まり）ので、行に理由を出す
  - **自動で決まる色**（主役の色・強調色の文字・図形・淡い地、罫線）。変えられない（エンジンが DADS の決まりで作る）
  - **自動で濃くした色**（入れた色 → 使う色）
  - 部品は一度だけ作って値だけを差し替える（作り直すと、色を選んでいる最中に選ぶ窓が閉じる）
- ブランドの色に `ink`・`muted` を足した（人が決めたときだけ持ち、エンジンのテーマの ink・muted にそのまま渡す）
- 「詳細設定（色の上書き）」はやめた。スライドに効かない上書き（情報色・主役色（淡・濃）・区切り線）は画面から外し、
  人が決めた値は保存のたびに持ち越す（`palette.custom_roles`・`merge_brand_config`）
- 説明文は見出しの横の「？」（`<details>`。押して開く・外を押すか Esc で閉じる）にしまう。ロゴは「背景が透明な PNG」をすすめる
- 「書式」の節はやめ、入るページで節を分ける。フッター（表示文字は左下に固定・ページ番号は中央に固定。中身のページだけ）と、ウォーターマーク（表示文字。全ページ・いちばん下の端の中央に薄く）。欄の中に例文は置かない（DADS: プレースホルダーを使わない）
- 見本はスワイプとクリック（左の 3 分の 1 は前・ほかは次）でも送れる
- 角の小さな絵の印は、サーバのカタログ（`logo_control.corners[].mark`）の位置を描く（画面は角の名前から位置を作らない）
- 保存のあとに画面全体の色をブランドの色に塗り替える処理（`SS.applyBrandTheme`）はやめた。画面は DADS の色のまま
- 設定のトップ（`/settings`）は H1「設定」と、各設定（ブランド `/settings/brands`・スライドスタイル・アクセス）へのリンクの一覧。各設定の画面はパンくず（設定 › いまの画面）→ H1。タブはやめた（狭い画面で崩れるため・2026-10-12）。上部バーの「設定」はアイコン＋文字で、現在地はホーム・スライドと同じ太字と下の線

## 却下した案

- **画面の JS で色の役を計算する**: 正本が 2 つになり、エンジンを直したときにずれる
- **サーバに deck.py をそのまま import する**: 台本・型・字体の測り（PIL）まで連れてきて、`cache`・`places` などの名前を
  サーバの `sys.modules` に残す
- **見本を毎回エンジンで本当に描く**: Chrome と時間がかかる（P4 で見送った理由のまま）

## 残したこと

情報色・主役色（淡・濃）・区切り線の上書きは、いまのエンジンのテーマに渡らない（`palette.engine_theme`）。画面からは外したが、
保存済みの値は消さずに持ち越す。主役の色・強調色の図形・淡い地を人が変えられるようにするには、エンジン（`deck_palette`）に
上書きを受け取る口を作る必要がある（今回は見送った）。

# 0014 取り込んだページ（PPTX から）の文字を、見た目を保ったまま直す

- 日付: 2026-10-14
- 状態: 採用
- 関係: `docs/adr/0011-import-pptx.md`・`docs/adr/0013-overlay-illustrations.md`・`docs/adr/0008-edit-kinds.md`

## 決めたこと

- 取り込んだページの修正の欄に「文字」を出す（「挿絵」と並べる）。**札を選ばずに書いて送った指示も「文字」として直す**。1 ページずつ
- ページの HTML のタグの間の文字（見出し・各行・箇条書きの印）に番号を振って台本係に渡す（`importing.text_segments`）。
  台本係は **番号ごとの直した文字だけ**を返し（`{"changes": [{"n", "text"}], "summary"}`）、サーバがその文字だけを差し替える
  （`importing.replace_texts`。文字はエスケープし、前後の空白は元のまま）。位置・色・書式・図形・画像・アニメーションは変えない
- 箇条書きの印だけの文字は「直さない」と添える。番号は増やせず、文字を空にもできない（消すことはできない）
- 元の字数から大きく増やした答え（2 倍か、元＋20 字を超える）は書き直させる
- **直した文字が箱からはみ出したら書き直させる**（エンジンの検査の `[text-overflow]` の警告のうち、直した文字のもの。
  取り込んだページのはみ出しは字体の違いでもともと出ることがあるので、ほかは警告のまま。最後の回は止めない）
- 一覧に出す見出し（取り込みの `title`）も、同じ文字を直したら直す
- 直すところが無いと台本係が答えたら、その理由を添えて失敗にする（画面の帯に出る）

## 理由

- 取り込んだ資料で一番よく直すのは文字。見た目を保ったまま直せないと、取り込んだ意味が薄い
- 台本係に HTML を書き換えさせると、位置・書式を壊しうる。番号の文字だけを受け取れば、確かめるのは文字の中身と長さだけで済む
- 箱の大きさは変わらないので、長くなった文字ははみ出す。挿絵を重ねたページでは、はみ出した文字が挿絵の下に潜る（実際に起きた）

## 却下した案

| 案 | 却下の理由 |
|---|---|
| 型のページとして書き直す | 見た目が元の PPTX から型のものに変わる |
| 台本係にページの HTML を直接書き換えさせる | 位置・書式・アニメーションを壊しうる。確かめにくい |
| 文字の箱を文字に合わせて広げる | ほかの図形・挿絵と重なる。元の配置を変えることになる |

## 残したこと

- 文字の行を足す・消す（箇条書きの項目を増やすなど）
- 書式（太字・色・大きさ）を変える

# 会話に貼る初回導入プロンプト

プラグインがまだ入っていない状態から、Codex または Claude Code に導入を頼むための文です。
通常のチャットではなく、手元のファイルとコマンドを扱える会話を使ってください。
下の文をまとめて貼ります。手元のフォルダから入れるときは、配布元の欄をそのフォルダの場所に書き替えます。
両方を使う場合も、まず会話しているアプリに導入し、その後もう一方で同じ手順を行います。

```text
Quick Slide をこの機械で使えるように導入してください。
配布元: https://github.com/mrkm86/quick-slide

まず README と docs/INSTALL.md を読み、会話しているアプリに
Quick Slide プラグインを登録・インストールしてください。
既存のプラグイン一覧を確認し、同じ名前で別の配布元が登録されていたら
勝手に置き換えず、その違いを教えてください。他のプラグインの設定は保持してください。

Codex は codex plugin marketplace add と codex plugin add、
Claude は claude plugin marketplace add と claude plugin install を使います。
各 CLI の --help でこの版に対応する操作を確認してください。
CLI で対応できない部分は、デスクトップアプリで行う具体的な操作を教えてください。
非公開の配布元にアクセスできないときは、必要な権限・認証を案内してください。
公開設定は変更せず、秘密鍵・パスワード・トークンを会話に貼るよう求めないでください。

インストール後の場所を確認し、そこにある
skills/quick-slide-setup/SKILL.md を読んでセットアップを進めてください。
Python 3.12 以上を使い、Windows では py -3 を使ってください。
必要な依存ソフトを診断し、管理者権限なしで導入できるものは入れてください。
管理者権限や全体へのインストールが必要な操作は、内容を説明してから確認してください。
ログインは私が行います。画像生成は ChatGPT にログインした Codex CLI を使い、
従量課金 API を既定にしないでください。

最後に診断し直し、サーバを起動して同梱の見本を開いてください。
内蔵ブラウザが使えればそこで確認し、使えなければ画面の URL を返してください。
Codex の砂場からサーバを起動できない場合は、私のターミナルで実行するコマンドを教えてください。
アプリの再起動や新しい会話が必要なら、その時点で次の操作を教えてください。

導入した版、使える形式、確認できた範囲、残る操作を短く報告してください。
今後「Quick Slide を更新して」と頼めるよう、登録した配布元を保持してください。
```

## 利用者が行う操作

アカウントへのログイン、必要なアクセス権の取得、アプリの再起動は利用者が行います。
CLI が未導入なら、その導入も必要です。一度の依頼で進められる範囲は、アプリの権限と機械の状態によります。
プラグインの更新手順は [導入・検証ガイド](INSTALL.md#更新する) にあります。
